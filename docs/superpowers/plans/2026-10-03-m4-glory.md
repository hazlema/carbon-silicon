# M4 "Glory" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monthly seasons with per-game Elo and standings, a hall of fame, a `/leaderboard` page, profile Standing and stats, a ranked grace week and practice games, a #lobby announcement when a month closes, and residents who know their rank.

**Architecture:** Ratings are never stored. A pure module (`ratings.ts`) replays a season's rated matches into Elo and standings; `LeaderboardManager` feeds it rows and caches the result in memory (closed seasons forever, open ones until the next `match.finished`). Whether a match is rated is decided once, at match creation (`ranked.ts`), from `identities.ranked_at` and each seat's finished-match count in that game. A once-a-minute check closes past seasons through a `season_closings` row (the idempotency guard) and announces the champions.

**Tech Stack:** Bun, TypeScript, Hono, Drizzle (PGlite / Postgres), SvelteKit (Svelte 5 runes), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-03-m4-glory-design.md`

## Global Constraints

- Season = UTC calendar month, `YYYY-MM`, from `seasonOf()` in `@cs/shared/protocol`. A match belongs to the season it was created in.
- Elo: start 1000 per season per game; K = 32 for a player's first 10 rated games of the season in that game, 16 from the 11th; 3–4 players: every pair by placement index, K divided by `players − 1`; all changes from pre-match ratings; floats stored, shown rounded.
- Points: sole first place = win, 3; shared first place or no winners = draw, 1 (no winners: every seat draws); everyone else = loss, 0. Order: points, wins, Elo, handle (case-insensitive). Ranks are unique, 1-based.
- Ranked: `ranked_at <= now` and (agent or locked human). Humans get `created_at + 7 days`; agents `created_at`. Guests never ranked.
- Practice: every player's first 3 finished (`over`) matches of each game; `meta.practiceGames` overrides; abandoned matches don't count.
- A match is rated iff every seat is ranked and past its practice games, decided at creation and frozen.
- **Nobody is told at the table.** No chip, no verdict sentence, no `rated` on `MatchSummary` or any match wire. The leaderboard and the profile are the only places the truth shows.
- Announcement text, exactly: `September is in the books. Champions: Critical Mass — @GAME_OVER · Crown & Steel — @Frosty. October is open; every rating is back to 1000.` / with none: `August is in the books. No ranked games were played. October is open; every rating is back to 1000.` Posted with `comms.postSystem('lobby', …)`.
- Standing text, exactly: `Standing: Unranked games · 4 days remaining` (days rounded up; `1 day remaining`), `Standing: All games are ranked`, guest `Standing: Unranked · lock your name to be ranked`.
- Confirm text, exactly: `Go ranked now? Every game you play from now on counts. This can't be undone.` buttons **Go ranked** · **Not yet**. Built into the page — never `confirm()`.
- Empty board: `No ranked games of Lightline yet this month. The first win takes 1st place.` / past: `No ranked games of Lightline in September.` Empty hall: `The first champions are crowned when this month ends.`
- Visual: the existing after-hours periodic table tokens (`--carbon`, `--silicon`, `--fog`, `--dust`, `--lattice`, `.panel`); no new colours. Works at 400 px with no horizontal page scroll.
- Never touch `.data/`. Run tests in the foreground. Commit messages in the repo's style ("Leaderboard: …"), ending with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Verify command for the whole repo: `bun run verify` (typecheck, unit, build, e2e).

## Rulings made while planning (record in `docs/m4-carryover.md` at the end)

- R-P1 — `ProfileGlory.rankedAt` carries the stored date for guests too (the spec said null). The web decides "guest" from `identity.locked`, so a player who locks their name on their own profile sees "7 days remaining" at once instead of the stale guest line. `ranked` is still false for guests.
- R-P2 — The guest Standing line's "lock your name" is plain text, not a link: on your own profile the lock form is in the settings column right beside it.
- R-P3 — `TableContext.ranks` is optional (`ranks?: string | null`), so the existing literal contexts in tests stay valid.
- R-P4 — The standings cache also carries a generation counter: a query that started before a `match.finished` never stores its (stale) result.

```ts
  /** "Go ranked now" (M4): ends a locked human's grace week today. One-way; asking again changes nothing. */
  async goRanked(identity: IdentityPublic): Promise<{ rankedAt: string }> {
    const row = await this.require(identity.id);
    if (row.kind !== 'human') throw forbidden('HUMANS_ONLY', 'Agents are ranked from their first game.');
    if (!row.passwordHash) throw forbidden('LOCK_FIRST', 'Lock your name first; guests are never on the board.');
    const now = new Date(this.clock.now());
    if (row.rankedAt && row.rankedAt.getTime() <= now.getTime()) return { rankedAt: row.rankedAt.toISOString() };
    await this.db.update(identities).set({ rankedAt: now }).where(eq(identities.id, row.id));
    return { rankedAt: now.toISOString() };
  }
```

```ts
import { and, count, eq, inArray } from 'drizzle-orm';
import type { IdentityPublic } from '@cs/shared/protocol';
import type { DB } from '../db';
import { identities, matches, matchPlayers } from '../db/schema';

/** Every player's first finished matches of each game are practice: they never count (M4). */
export const PRACTICE_GAMES = 3;

/**
 * Whether a match about to start will count on the leaderboard: every seat is ranked (an agent, or a
 * locked human past their first week) and has finished its practice games in this game. Decided once,
 * at creation; nobody at the table is told.
 */
export async function isRatedMatch(
  db: DB,
  gameId: string,
  players: IdentityPublic[],
  now: number,
  practiceGames = PRACTICE_GAMES,
): Promise<boolean> {
  if (players.some((p) => p.kind === 'human' && !p.locked)) return false;
  const ids = players.map((p) => p.id);
  const rows = await db.select({ id: identities.id, rankedAt: identities.rankedAt }).from(identities).where(inArray(identities.id, ids));
  if (rows.length !== ids.length || rows.some((r) => !r.rankedAt || r.rankedAt.getTime() > now)) return false;
  if (practiceGames <= 0) return true;
  const played = await db
    .select({ id: matchPlayers.identityId, n: count() })
    .from(matchPlayers)
    .innerJoin(matches, eq(matches.id, matchPlayers.matchId))
    .where(and(eq(matches.gameId, gameId), eq(matches.status, 'over'), inArray(matchPlayers.identityId, ids)))
    .groupBy(matchPlayers.identityId);
  const n = new Map(played.map((r) => [r.id, Number(r.n)]));
  return ids.every((id) => (n.get(id) ?? 0) >= practiceGames);
}
```

```ts
let n = 0;
/** A match from a best-first placement of player ids; seats are s0, s1, … in that order. */
function match(placement: string[][], winners?: string[]): RatedMatch {
  const seats = placement.flat().map((playerId, i) => ({ seat: `s${i}`, playerId }));
  const seatOf = (p: string) => seats.find((s) => s.playerId === p)!.seat;
  const groups = placement.map((g) => g.map(seatOf));
  return { id: `m${++n}`, outcome: { winners: (winners ?? (groups.length > 1 ? groups[0].map((s) => s) : [])).map((x) => x), placement: groups }, seats };
}
```

```ts
/** Elo and standings for one season of one game, replayed from its rated matches (M4). No I/O. */

export const START_ELO = 1000;
export const K_NEW = 32;
export const K_SETTLED = 16;
/** A player's first this-many rated games of the season use K_NEW. */
export const K_NEW_GAMES = 10;
export const WIN_POINTS = 3;
export const DRAW_POINTS = 1;

export interface RatedMatch {
  id: string;
  outcome: { winners: string[]; placement: string[][] };
  seats: { seat: string; playerId: string }[];
}

export interface SeasonLine {
  playerId: string;
  points: number;
  wins: number;
  draws: number;
  losses: number;
  games: number;
  elo: number;
}

/** Sole first place wins; shared first place or no winners at all is a draw; everyone else loses. */
export function resultOf(outcome: RatedMatch['outcome'], seat: string): 'win' | 'draw' | 'loss' {
  if (outcome.winners.length === 0) return 'draw';
  if (!outcome.winners.includes(seat)) return 'loss';
  return outcome.winners.length === 1 ? 'win' : 'draw';
}

/** A seat's placement group (0 is best); a seat missing from the placement counts as last. */
function placeOf(placement: string[][], seat: string): number {
  const i = placement.findIndex((g) => g.includes(seat));
  return i === -1 ? placement.length : i;
}

/** Replays `list` in order. Every pair is compared by placement; changes come from pre-match ratings. */
export function rateSeason(list: RatedMatch[]): SeasonLine[] {
  const lines = new Map<string, SeasonLine>();
  const lineOf = (playerId: string): SeasonLine => {
    let l = lines.get(playerId);
    if (!l) {
      l = { playerId, points: 0, wins: 0, draws: 0, losses: 0, games: 0, elo: START_ELO };
      lines.set(playerId, l);
    }
    return l;
  };
  for (const m of list) {
    if (m.seats.length < 2) continue;
    const players = m.seats.map((s) => ({ seat: s.seat, line: lineOf(s.playerId), place: placeOf(m.outcome.placement, s.seat) }));
    const before = players.map((p) => p.line.elo);
    const k = players.map((p) => (p.line.games < K_NEW_GAMES ? K_NEW : K_SETTLED) / (players.length - 1));
    const delta = players.map(() => 0);
    for (let i = 0; i < players.length; i++) {
      for (let j = i + 1; j < players.length; j++) {
        const expected = 1 / (1 + 10 ** ((before[j] - before[i]) / 400));
        const actual = players[i].place < players[j].place ? 1 : players[i].place > players[j].place ? 0 : 0.5;
        delta[i] += k[i] * (actual - expected);
        delta[j] += k[j] * (expected - actual);
      }
    }
    players.forEach((p, i) => {
      p.line.elo = before[i] + delta[i];
      p.line.games += 1;
      const result = resultOf(m.outcome, p.seat);
      if (result === 'win') {
        p.line.wins += 1;
        p.line.points += WIN_POINTS;
      } else if (result === 'draw') {
        p.line.draws += 1;
        p.line.points += DRAW_POINTS;
      } else {
        p.line.losses += 1;
      }
    });
  }
  return [...lines.values()];
}

/** Standings order: points, wins, Elo, then handle (case-insensitive), so every rank is unique. */
export function rankLines<T extends SeasonLine>(lines: T[], handleOf: (playerId: string) => string): (T & { rank: number })[] {
  return [...lines]
    .sort(
      (a, b) =>
        b.points - a.points ||
        b.wins - a.wins ||
        b.elo - a.elo ||
        handleOf(a.playerId).toLowerCase().localeCompare(handleOf(b.playerId).toLowerCase()),
    )
    .map((l, i) => ({ ...l, rank: i + 1 }));
}
```

```ts
  constructor(

    private deps: LeaderboardDeps,

    deps.bus.on('match.finished', () => this.dropOpen());

  async tally(season: string): Promise<Tally> {

  async standings(season: string, gameId: string): Promise<StandingRow[]> {
    const closed = await this.closedSeasons();
    const key = `${season}:${gameId}`;
    const hit = this.cache.get(key);
    if (hit) return hit;
    const generation = this.generation;
    const rows = await this.db
      .select({ matchId: matches.id, outcome: matches.outcome, seat: matchPlayers.seat, i: identities })
      .from(matchPlayers)
      .innerJoin(matches, eq(matches.id, matchPlayers.matchId))
      .innerJoin(identities, eq(identities.id, matchPlayers.identityId))
      .where(and(eq(matches.season, season), eq(matches.gameId, gameId), eq(matches.status, 'over'), eq(matches.rated, true)))
      .orderBy(asc(matches.endedAt), asc(matches.id), asc(matchPlayers.seat));
    const people = new Map<string, IdentityRow>();
    const list: RatedMatch[] = [];
    const byId = new Map<string, RatedMatch>();
    for (const r of rows) {
      let m = byId.get(r.matchId);
      if (!m) {
        const o = r.outcome as { winners?: unknown; placement?: unknown } | null;
        if (!o || !Array.isArray(o.winners) || !Array.isArray(o.placement)) {
          this.warnOnce(r.matchId);
          continue;
        }
        m = { id: r.matchId, outcome: { winners: o.winners as string[], placement: o.placement as string[][] }, seats: [] };
        byId.set(r.matchId, m);
        list.push(m);
      }
      people.set(r.i.id, r.i);
      m.seats.push({ seat: r.seat, playerId: r.i.id });
    }
    const board = rankLines(rateSeason(list), (id) => people.get(id)!.handle).map((l) => ({
      rank: l.rank,
      identity: toPublic(people.get(l.playerId)!),
      points: l.points,
      wins: l.wins,
      draws: l.draws,
      losses: l.losses,
      games: l.games,
      elo: Math.round(l.elo),
    }));
    if (generation === this.generation || closed.has(season)) this.cache.set(key, board);
    return board;
  }

  /** Every season with at least one match, plus the current one, newest first. */
  async seasons(): Promise<SeasonInfo[]> {
    const rows = await this.db.selectDistinct({ season: matches.season }).from(matches);
    const closed = await this.closedSeasons();
    const all = new Set(rows.map((r) => r.season));
    all.add(seasonOf(this.deps.clock.now()));
    return [...all].sort().reverse().map((season) => ({ season, closed: closed.has(season) }));
  }

  /** Each closed season's first place per game: newest season first, games in catalog order. */
  async hallOfFame(): Promise<Champion[]> {
    const closed = [...(await this.closedSeasons())].sort().reverse();
    const out: Champion[] = [];
    for (const season of closed) {
      for (const g of this.deps.games()) {
        const [top] = await this.standings(season, g.id);
        if (top) out.push({ season, gameId: g.id, row: top });
      }
    }
    return out;
  }

  /** What a profile shows of the leaderboard: standing, this season's rows, matches played, titles. */
  async glory(identityId: string): Promise<ProfileGlory> {
    const [row] = await this.db.select().from(identities).where(eq(identities.id, identityId)).limit(1);
    const now = this.deps.clock.now();
    const pub = row ? toPublic(row) : null;
    const rankedAt = row?.rankedAt?.toISOString() ?? null;
    const ranked = !!pub && !(pub.kind === 'human' && !pub.locked) && rankedAt !== null && Date.parse(rankedAt) <= now;
    const current = seasonOf(now);
    const season: ProfileGlory['season'] = [];
    for (const g of this.deps.games()) {
      const mine = (await this.standings(current, g.id)).find((r) => r.identity.id === identityId);
      if (mine) season.push({ gameId: g.id, row: mine });
    }
    const [{ n }] = await this.db
      .select({ n: count() })
      .from(matchPlayers)
      .innerJoin(matches, eq(matches.id, matchPlayers.matchId))
      .where(and(eq(matchPlayers.identityId, identityId), eq(matches.status, 'over')));
    const titles = (await this.hallOfFame()).filter((c) => c.row.identity.id === identityId).map((c) => ({ season: c.season, gameId: c.gameId }));
    return { rankedAt, ranked, season, matchesPlayed: Number(n), titles };
  }

  protected async closedSeasons(): Promise<Set<string>> {
    if (!this.closed) {
      const rows = await this.db.select({ season: seasonClosings.season }).from(seasonClosings);
      this.closed ??= new Set(rows.map((r) => r.season));
    }
    return this.closed;
  }

  private dropOpen(): void {
    this.generation += 1;
```

```ts
   * Closes every past season that has matches, none of them still in countdown or live, and no
   * closing row yet. The insert is the guard: only the call whose insert lands announces, so a restart
   * or a second server never announces a season twice.
   */
  async closeSeasons(announcer: Announcer): Promise<string[]> {
    const now = this.deps.clock.now();
    const current = seasonOf(now);
    const closed = await this.closedSeasons();
    const past = (await this.db.selectDistinct({ season: matches.season }).from(matches).where(lt(matches.season, current)))
      .map((r) => r.season)
      .filter((s) => !closed.has(s))
      .sort();
    const done: string[] = [];
    for (const season of past) {
      const [busy] = await this.db
        .select({ id: matches.id })
        .from(matches)
        .where(and(eq(matches.season, season), inArray(matches.status, ['countdown', 'live'])))
        .limit(1);
      if (busy) continue;
      const inserted = await this.db
        .insert(seasonClosings)
        .values({ season, closedAt: new Date(now) })
        .onConflictDoNothing()
        .returning({ season: seasonClosings.season });
      closed.add(season);
      if (inserted.length === 0) continue;
      await announcer.postSystem('lobby', await this.announcement(season, current));
      done.push(season);
    }
    return done;
  }

  private async announcement(season: string, current: string): Promise<string> {
    const champions: string[] = [];
    for (const g of this.deps.games()) {
      const [top] = await this.standings(season, g.id);
      if (top) champions.push(`${g.name} — ${top.identity.released ? 'a former player' : `@${top.identity.handle}`}`);
    }
    const middle = champions.length > 0 ? `Champions: ${champions.join(' · ')}.` : 'No ranked games were played.';
    return `${monthName(season)} is in the books. ${middle} ${monthName(current)} is open; every rating is back to 1000.`;
```

```ts
import type { IdentityPublic, StandingRow } from '@cs/shared/protocol';

/** How many rows the board shows before pinning the viewer's own. */
export const BOARD_LIMIT = 50;
/** localStorage key for the last game tab picked. */
export const GAME_KEY = 'cs.leaderboard.game';

const month = (season: string, opts: Intl.DateTimeFormatOptions) =>
  new Date(`${season}-01T00:00:00Z`).toLocaleString('en-US', { ...opts, timeZone: 'UTC' });

/** "2026-09" → "September 2026". */
export const monthLabel = (season: string): string => month(season, { month: 'long', year: 'numeric' });
/** "2026-09" → "September". */
export const monthName = (season: string): string => month(season, { month: 'long' });

export function ordinal(n: number): string {
  const s = ['th', 'st', 'nd', 'rd'];
  const v = n % 100;
  return `${n}${s[(v - 20) % 10] || s[v] || s[0]}`;
}

/** The top of the board, and the viewer's own row pinned underneath when it's further down. */
export function boardRows(rows: StandingRow[], meId: string | null, limit = BOARD_LIMIT): { top: StandingRow[]; pinned: StandingRow | null } {
  const top = rows.slice(0, limit);
  if (!meId || top.some((r) => r.identity.id === meId)) return { top, pinned: null };
  return { top, pinned: rows.find((r) => r.identity.id === meId) ?? null };
}

export const boardName = (identity: Pick<IdentityPublic, 'handle' | 'released'>): string => (identity.released ? 'a former player' : identity.handle);

export function emptyBoardText(gameName: string, season: string, current: string): string {
  return season === current
    ? `No ranked games of ${gameName} yet this month. The first win takes 1st place.`
    : `No ranked games of ${gameName} in ${monthName(season)}.`;
}
```

```ts
import type { IdentityPublic, ProfileGlory } from '@cs/shared/protocol';
import { monthLabel } from './leaderboard';

const DAY = 86_400_000;

/** The profile's Standing line (without the "Standing: " label), and whether Go ranked now applies. */
export function standingOf(
  identity: Pick<IdentityPublic, 'kind' | 'locked'>,
  glory: Pick<ProfileGlory, 'rankedAt'>,
  now: number,
): { text: string; canGoRanked: boolean } {
  if (identity.kind === 'human' && !identity.locked) return { text: 'Unranked · lock your name to be ranked', canGoRanked: false };
  const at = glory.rankedAt ? Date.parse(glory.rankedAt) : now;
  if (at <= now) return { text: 'All games are ranked', canGoRanked: false };
  const days = Math.ceil((at - now) / DAY);
  return { text: `Unranked games · ${days} ${days === 1 ? 'day' : 'days'} remaining`, canGoRanked: identity.kind === 'human' };
}

export const titleText = (t: { season: string; gameId: string }, gameName: string): string => `Champion · ${gameName} · ${monthLabel(t.season)}`;
```

```ts
export interface RankRow {
  rank: number;
  elo: number;
  identity: { id: string; handle: string };
}

function ordinal(n: number): string {
  const s = ['th', 'st', 'nd', 'rd'];
  const v = n % 100;
  return `${n}${s[(v - 20) % 10] || s[v] || s[0]}`;
}

/** Where everyone at the table stands on this month's board for this game: you first, then seat order. */
export function ranksLine(gameName: string, rows: RankRow[], seats: { seat: string; identity: { id: string; handle: string } }[], you: string | null): string | null {
  if (seats.length === 0) return null;
  const ordered = [...seats.filter((s) => s.seat === you), ...seats.filter((s) => s.seat !== you)];
  const parts = ordered.map((s) => {
    const r = rows.find((x) => x.identity.id === s.identity.id);
    if (s.seat === you) return r ? `you are ${ordinal(r.rank)} (Elo ${r.elo})` : 'you have no ranked games yet';
    return r ? `@${s.identity.handle} is ${ordinal(r.rank)} (${r.elo})` : `@${s.identity.handle} has no ranked games yet`;
  });
  return `This month in ${gameName}: ${parts.join(', ')}.`;
}
```

```ts
/** This month's standings per game, fetched at most once a minute; null when the fetch fails or takes over 2 s. */
const boards = new WeakMap<Client, Map<string, { at: number; rows: RankRow[] }>>();
async function standingsOf(client: Client, gameId: string): Promise<RankRow[] | null> {
  let cache = boards.get(client);
  if (!cache) boards.set(client, (cache = new Map()));
  const hit = cache.get(gameId);
  if (hit && Date.now() - hit.at < 60_000) return hit.rows;
  let timer: ReturnType<typeof setTimeout> | undefined;
  const late = new Promise<null>((resolve) => (timer = setTimeout(() => resolve(null), 2000)));
  try {
    const rows = await Promise.race([
      client.call<{ rows: RankRow[] }>('GET', `/api/leaderboard?game=${encodeURIComponent(gameId)}`).then((r) => r.rows),
      late,
    ]);
    if (rows) cache.set(gameId, { at: Date.now(), rows });
    return rows;
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}
```
