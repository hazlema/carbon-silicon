# Salvo v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Salvo v1, the design doc's first cut: four hidden 8×8 seas, deployment, one shell per seat per round, simultaneous resolution, Time on Target, the Fog Lifts, scrap and the one-winner tiebreak, the three heatmap residents, a click-to-fire board with incoming-fire animation, and a rules guide — built against the engine as it is today, so that it runs now and runs better once the engine's `simultaneous` mode lands.

**Architecture:** One game package `games/salvo` (pure, tested, exports the module plus helpers the board and residents share). The residents' heatmap lives in `apps/bots/src/strategies/salvo.ts`. The board is `apps/web/src/lib/games/salvo/Board.svelte` (CSS grid of buttons, no canvas), wired into the table page like Crown & Steel. The engine (`apps/server/src/core/games.ts`) is **not** modified in this plan: another session is adding `simultaneous` mode. The module declares the fields that mode will read (`simultaneous`, `round`, `roundSummary`) through its own extended type, and keeps every narration safe on its own, so nothing leaks under today's engine either.

**Tech Stack:** TypeScript, bun test, SvelteKit 5 (runes), Playwright.

**Design:** `docs/ideas/Salvo — game design.md` (the spec) and `docs/ideas/Salvo — engine changes.md` (what the engine will do; read it to understand `round()` and `roundSummary()`). The house guide: `docs/creating-a-game.md`.

## Global Constraints

- **Never touch** `apps/server/src/core/games.ts`, `packages/game-api/src/types.ts`, or `.data/`. The engine change is someone else's; if a piece of this plan seems to need it, make the module do without (see Task 1's notes) and write the gap into `docs/salvo-carryover.md`.
- **Hidden information is the game.** Five invariants from the design doc hold at every step: (1) the spectator view (`view(state, null)`) is public only while live, everything once over; (2) no aim or placement appears in `describe()`, `narrate()`, or any text before the round resolves; (3) every animated event is in `lastVolley`; (4) hidden means absent from the view, not shown and left to memory; (5) `legal()` stays small (≤ about 200 entries in the fire phase).
- **Determinism.** All randomness through `createRng` from `@cs/game-api`, seeded from the state. Resolution order never depends on commit order.
- **State and commands are plain JSON** (no `undefined` in arrays, no Maps). `apply()` and `forfeit()` return new states (`structuredClone`).
- Residents read only their own seat's view (`MatchEnvelope.view`), never the state.
- Copy conventions: sentence case, plain words, no all-caps labels, no middle dots in UI strings.
- Commit messages: plain sentences ("Salvo: …"), then a blank line and `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Run every test in the foreground and wait for it. Unit: `bun test games/salvo`, `bun test apps/bots`, `cd apps/web && bun test src/lib`. Typecheck: `bun run typecheck`. Build: `bun run build`. E2e: one file per command, `bunx playwright test e2e/<file>.e2e.ts`.
- If a command you need is denied, stop and report `BLOCKED: <exact command>`; never route around a denial.

## Rulings made while planning (record in `docs/salvo-carryover.md` at the end)

- R-P1 — A ship's `facing` is `east` or `north` only: `at` is the ship's first cell and the hull runs toward the facing. A hull facing west from f3 is the same hull as one facing east from c3, so two facings enumerate every placement once, keeping deployment's `legal` under about 450 entries.
- R-P2 — Under today's engine, the module already keeps secrets: `describe()` returns "fires" / "deploys" / "deploys the fleet at random"; `narrate()` returns "is ready" / "deploys a ship" / "deploys the fleet"; the round's story is produced by `roundSummary()` (unused by today's engine; the board and residents read `lastVolley` instead). Today's engine will also reset the deadline per commit and demand exact revisions; the bots' 409 retry and the page's 409 refetch cope with that. All of this is carried over as "better once simultaneous lands".
- R-P3 — Cells you have already fired at on a sea leave your `legal` for that sea (the design's wording). Firing at a cell someone else already hit is legal and lands as a `hit` with no new scrap (the cell was already hit); it exists so that two seats can aim a Time on Target at a known hit and blast its neighbours.
- R-P4 — An eliminated seat is `isOut` (released by today's engine). Its sea is no longer a target; shells already in the air at it this round still land and still score.
- R-P5 — Forfeit (resign, three timeouts, disconnect) during deployment or fire: the seat is eliminated with the forfeit reason, its fleet stays on the board as a wreck (public), and if every other living seat was already `ready`, the round resolves at once.
- R-P6 — `turnSeconds` is 45 (the design's guess; tune in playtests). Deployment uses the same number.
- R-P7 — The scrap for eliminating a seat (half its scrap, rounded down) goes to every seat credited with sinking its last ship.
- R-P8 — The board is a CSS grid of real buttons on a tilted slab (CSS 3D like Critical Mass's slab, but no drag-to-swivel: a fixed isometric tilt with a Top toggle), so keyboards, screen readers and tests work with no canvas hit-testing. Incoming fire is CSS-animated DOM elements driven from `lastVolley`.
- R-P9 — No new hero art is needed to ship v1: `thumbnail.jpg` and `hero.jpg` are produced by the Proprietor after the build (OpenArt, rule 17). The rules guide references `hero.jpg`; until the file exists the guide renders without a cover (the rules page handles a missing cover).

## Review Focus

1. **The leak fuzz** (Task 1): a few hundred seeded playthroughs; after every command and resolution, no unrevealed ship cell and no uncommitted aim appears in the spectator view, in another seat's view, in `describe()`, `narrate()` or `roundSummary()` of the *previous* state.
2. **Order-free resolution** (Task 1): the same commits applied in every order of seats give identical states (compare JSON).
3. **Exactly one winner** (Task 1): forced same-volley knockouts go through the tiebreak; `winners.length === 1` in every fuzzed game.
4. **The click reaches the server** (Task 4 e2e): a human fires a real shell at a real cell and the next envelope's `lastVolley` (after the residents fire) contains that shell from that seat.
5. **Residents never read state** (Task 3): the strategy's signature takes a `SalvoView`; grep for `SalvoState` in `apps/bots` finds nothing.

```ts
// games/salvo/src/index.ts
export const SEATS = ['north', 'east', 'south', 'west'] as const;
export const SIZE = 8;                       // 8×8 seas, cells a1..h8, a1 bottom-left
export const TURN_SECONDS = 45;
export const FOG_FROM = 10;                  // the first round with a lifted row
export const ROUND_CAP = 30;
export const SHIPS: readonly { id: ShipId; length: number }[] = [
  { id: 'cruiser', length: 4 }, { id: 'destroyer', length: 3 }, { id: 'frigate', length: 3 }, { id: 'submarine', length: 2 },
];
export type ShipId = 'cruiser' | 'destroyer' | 'frigate' | 'submarine';
export type Facing = 'east' | 'north';
export type Phase = 'deploy' | 'fire' | 'over';
export type ShotResult = 'miss' | 'hit' | 'sunk';

export interface Ship { id: ShipId; cells: string[]; hits: string[] }           // hits ⊆ cells
export interface Shell { from: SeatId; sea: SeatId; cell: string }               // one committed shot
export interface ShellResult extends Shell { result: ShotResult; ship: ShipId | null; blast: boolean }
/** Time on Target: a cell two or more seats hit at once, and the 3×3 it took with it. */
export interface Blast { sea: SeatId; cell: string; by: SeatId[]; cells: string[]; hits: string[] }
export interface Volley { round: number; shells: ShellResult[]; blasts: Blast[]; sunk: { sea: SeatId; ship: ShipId; by: SeatId[] }[]; eliminated: SeatId[] }

export interface SalvoState {
  seats: SeatId[];
  seed: number;
  draws: number;                              // how many times the rng has been used (random deployment); advances with each use
  phase: Phase;
  round: number;                              // 0 during deploy, then 1, 2, …
  fleets: Record<SeatId, Ship[]>;             // placed ships; ships not here are still in port
  /** Every cell shot at each sea, with its result and who shot it (public once resolved). */
  shots: Record<SeatId, Record<string, { result: 'miss' | 'hit'; by: SeatId[] }>>;
  pending: Record<SeatId, Shell | null>;      // this round's secret commits
  ready: SeatId[];                            // seats committed this round (public)
  lastVolley: Volley | null;
  scrap: Record<SeatId, number>;
  hitsLanded: Record<SeatId, number>;
  eliminated: { seat: SeatId; round: number; reason: string }[]; // in order; reason 'sunk' | 'resign' | 'timeout' | …
  timeouts: Record<SeatId, number>;           // unused by the module (the engine counts); keep 0
  winner: SeatId | null;
  endReason: string | null;                   // 'last-afloat' | 'tiebreak' | 'round-cap' | 'resign' | 'timeout' | …
}

export type SalvoCommand =
  | { place: ShipId; at: string; facing: Facing }
  | { place: 'random' }
  | { fire: 'shell'; at: SeatId; cell: string };

export interface TargetView {
  sea: SeatId;
  mine: { cell: string; result: ShotResult }[];        // your own shots at this sea, oldest first
  hits: string[];                                      // every hit cell anyone landed (public)
  misses: string[];                                    // every miss anyone landed (public)
  sunk: { ship: ShipId; cells: string[] }[];           // sunk ships with their cells (public)
  lifted: { row: number; cells: string[] }[];          // lifted rows and the ship cells seen in them (public)
  afloat: number;                                      // ship cells still unhit (public: 12 − hits)
}
export interface SalvoView {
  you: SeatId | null;
  seats: SeatId[];
  round: number;
  phase: Phase;
  ready: SeatId[];
  /** Your fleet: every ship, its cells and hits; ships still in port are listed with `cells: []`. Null for spectators. */
  mySea: { ships: Ship[]; port: ShipId[]; shots: Record<string, 'miss' | 'hit'> } | null;
  targets: TargetView[];                               // one per sea that is not yours and not eliminated (spectators: every living sea)
  lastVolley: Volley | null;
  scrap: Record<SeatId, number>;
  eliminated: SeatId[];                                // in elimination order
  liftedRows: number[];                                // the rows public this round (same for every sea)
  winner: SeatId | null;
  endReason: string | null;
  ascii: string;
}

export const salvoGame: GameModule<SalvoState>;        // default export too
export function cellIndex(cell: string): number | null; // 'a1' → 0 … 'h8' → 63, case-insensitive, null if off the sea
export function cellName(i: number): string;
export function neighbours(cell: string): string[];   // the 8 around it, on the sea
export function liftedRows(round: number): number[];  // [] before FOG_FROM; then 8, 1, 7, 2, 6, 3, 5, 4 cumulative
export function hullCells(at: string, length: number, facing: Facing): string[] | null; // null if it leaves the sea
export function roundSummary(before: SalvoState, after: SalvoState): string[]; // the round's story, also exposed on turn
export function renderAscii(view: Omit<SalvoView, 'ascii'>): string;
```

**Behaviour to implement:**

- `setup({ seats, seed })`: 2–4 seats (`BAD_SEATS` otherwise); `phase: 'deploy'`, `round: 0`, empty fleets, zeros everywhere.
- Deployment: `toMove` = living seats with a ship still in port. `legal(seat)` = every `{place, at, facing}` for each ship in port that fits and overlaps nothing (ships may touch), plus `{place:'random'}` when any ship is in port. `apply` codes: `BAD_COMMAND` (shape), `BAD_SHIP` (unknown or already placed), `BAD_CELL`, `BAD_FACING`, `OFF_SEA` (hull leaves the sea), `OVERLAP`, `NOT_YOUR_TURN` when the seat owes nothing, `GAME_OVER`. `random` places every ship still in port with the seeded rng (advance `draws`; use `createRng(seed + draws * 7919)` style so each use differs and is deterministic), retrying placements until they fit. When the last fleet is complete: `phase = 'fire'`, `round = 1`.
- Fire: `toMove` = living seats not in `ready`. `legal(seat)` = `{fire:'shell', at, cell}` for each living opponent sea and each cell not already in that seat's own shots at that sea (R-P3). `apply` stores the shell in `pending[seat]`, adds the seat to `ready`; codes `BAD_TARGET` (not a living opponent sea), `BAD_CELL`, `ALREADY_FIRED` (you shot that cell on that sea before), `NOT_YOUR_TURN` when already ready. When `ready` covers every living seat, **resolve** inside the same `apply`.
- Resolve (pure function `resolve(s)` so forfeit can call it too): group pending shells by sea and cell, in seat order of `s.seats` (never by commit order). For each (sea, cell) with ≥ 2 shooters, a Blast: cells = cell + `neighbours(cell)`; every ship cell among them not already hit becomes a hit credited to *every* shooter of the blast; `ShellResult.blast = true` for those shells. Single shells: miss, hit, or sunk (the hit completes a ship). Record shots in `s.shots[sea][cell]` (merge `by`). Scrap: +1 per new hit cell per credited seat; +3 per sunk ship per credited seat; `hitsLanded` +1 per new hit cell per credited seat. Then eliminations: any living seat whose ships are all sunk → `eliminated.push({seat, round, reason:'sunk'})`, and every seat credited with sinking its last ship gets `floor(scrap[victim] / 2)` (R-P7). Then the end check: one living seat → winner, `last-afloat`; zero living → tiebreak among the seats eliminated this round: most scrap, then most `hitsLanded`, then a seeded coin flip (`createRng(seed ^ round)`), `endReason: 'tiebreak'`; the others share second place. Else if `round >= ROUND_CAP` → most afloat ship cells among the living, then the tiebreak order, `round-cap`. Else `round += 1`, `ready = []`, `pending` cleared, `lastVolley` set. The Volley lists every shell in seat order.
- Fog: `liftedRows(round)`; the view's `targets[].lifted` lists, for each lifted row, the ship cells in that row (hit or not) — unhit ones are what the fog reveals.
- `outcome`: null until `winner`; `placement` = `[[winner], …eliminated groups newest first]`, where seats eliminated in the same round share an inner array (the tiebreak losers share second).
- `forfeit(state, seat, reason)`: no-op if over or already out; else eliminate with `reason`, drop from `ready`/`pending`; if in fire phase and every remaining living seat is ready → resolve; if one living seat remains → winner with `endReason = reason`. In the deploy phase, if all remaining fleets are complete, start round 1.
- `isOut(s, seat)` = eliminated includes seat.
- `view(s, seat)`: as the interface. `mySea.shots` is every shot landed on your sea (`cell → result`). `targets` for seat = living seas other than yours; for spectators every living sea (plus, once `over`, every sea with every ship revealed: add `revealed?: Ship[]` to `TargetView` when the match is over). Nothing from `pending` ever appears, for anyone, including `you`'s own pending (the `ready` list is enough; keep the view honest and small).
- `turn`: `turnSeconds: TURN_SECONDS`, `simultaneous: true`, `round: (s) => s.round` (deploy = 0), `toMove`, `legal`, `apply`, `describe(cmd)` → `'fires'` | `'deploys a ship'` | `'deploys the fleet'` (never a cell, sea or ship), `narrate(before, after, seat, cmd)` → `'is ready'` | `'deploys a ship'` | `'deploys the fleet'`, `roundSummary(before, after)`: `[]` unless `after.round !== before.round` (or the phase changed to over); then lines like `"Round 3: {north} hits {east} at e5, {south} misses {east}, {west} sinks {north}'s submarine."` (seats as `{seat}` placeholders, as Critical Mass does), one line for each Blast (`"Time on Target at {east} e5 by {north} and {south}: 9 cells, 3 hits."`), one per elimination (`"{east} is out."`), one for a lifted row (`"The fog lifts from row 8."`), and the verdict when over (`"Both fleets go down together. {east} had more scrap. {east} takes it."`). Deployment ending: `["All fleets are down. Round 1 begins."]`.
- `ascii`: all seas, your own with ships (`C D F S` letters for unhit ship cells, `X` hits, `o` misses, `.` unknown, `~` lifted empty), each sea headed by its seat and, for you, "(you)"; a legend line. Spectators: no ships except lifted/sunk/revealed.

- Deployment: all strengths place at random (`{place:'random'}` when offered).
