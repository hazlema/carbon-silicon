# Milestone 3a "Engine" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real-time games. A generic doctrine validator and evaluator, a real-time runner inside the existing game manager with a 300 ms reaction floor, and Lightline (neon light-cycles), playable by agents over HTTP and by house bots, watchable in the browser, and machines-only until M3b.

**Architecture:**
- `packages/game-api` gains pure `validateDoctrine` and `evaluate`.
- `games/lightline` is a new pure, deterministic game module.
- In `apps/server/src/core/games.ts`, `GameManager` keeps one lifecycle for every match. For a game with `realtime` rules it runs a tick loop instead of turns, and a small `DoctrineDesk` (`apps/server/src/core/realtime.ts`) keeps each seat's doctrine, the floor (counted in ticks) and the fired rules.
- Everything around a match (tables, results, chat, spectating, rematch) is shared with Critical Mass.

**Tech Stack:** Bun 1.3.13, TypeScript 6.0.3, Hono 4.13.9, Drizzle ORM 0.45.3, @electric-sql/pglite 0.5.8, Svelte 5.57.1 + SvelteKit 2.70.3, Playwright 1.63.0. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-29-m3a-engine-design.md` (all of it), extending `docs/superpowers/specs/2026-09-26-robot-games-design.md` (§ Doctrine, which holds the reaction-floor decision, and § Lightline). Read the M3a spec before starting.

## Review Focus

1. **A script that sends a new doctrine every tick.** Expected: at most one change applies per 3 ticks. The newest pending change replaces older ones, and nothing is refused for coming too soon. Pinned in Task 3.
2. **A seat resigning mid-round while the others play on** (3–4 players). Expected: ticks keep coming (`startTurn` must not clear the tick timer), the round resolves, and the resigned seat places last. Pinned in Task 2 (engine) and Task 3 (runner).
3. **A malformed doctrine:** a sense compared with a sense of another type, conditions nested 9 deep, a 20 KB body, an unknown parameter. Expected: a precise 400 (or 413), never a 500. Pinned in Task 1 and Task 4.
4. **A human at every door of a machines-only game:** hosting, vs house, sitting at an open table, accepting an invite, being invited, quick match. Expected: `403 MACHINES_ONLY`, with the table and queue untouched. Pinned in Task 4.
5. **A tick that throws** (a bug in a game's `step` or `senses`). Expected: it's logged, the match keeps ticking, and the server stays up. Pinned in Task 3.

## Rulings made while planning

- **R-P1. The floor is counted in ticks** (`ceil(floorMs / tickMs)`, 3 for Lightline). Deterministic, testable on the fake clock, and a slow server can't stretch or shrink it.
- **R-P2. During the countdown a doctrine change applies at once** and doesn't start the floor. Nothing moves yet, so there's no reaction to gain.
- **R-P3. Two test-only speed options, `realtimeTickMs` and `realtimeCountdownMs`,** for tests and the e2e server. Production uses the game's own `tickHz` and `countdownSeconds`.
- **R-P4. A tick that throws is logged and skipped;** the next tick is still scheduled. One bad step shouldn't freeze a match or take the server down.
- **R-P5. The house bots re-send their doctrine only when `shrinking` flips.** They check once a second, well inside the floor.
- **R-P6. Every trail and head cell is marked in the grid**, so "two cycles swap cells head-on" is simply both entering a non-free cell. It needs no separate rule, and gives the same outcome as the spec.
- **R-P7. A resign during a real-time countdown leaves the countdown running for the others.** The turn-based trick of flipping the match live at once would skip `goLive`, and with it the tick loop. If the resign ends the match, `finish` clears the countdown timer.
- **R-P8. The residents' rule labels differ from the default doctrine's** (`ride`, `veer-left`…; `CORNER`, `PROCEED`…). A watcher, and the tests, can then tell a bot riding its own orders from one riding the default.
- **R-P9. The Lightline e2e test resigns its stand-in rider when it ends.** A 2-player match then ends at once, so Sprocket is free for the tests that run after it.

```ts
import { GameRuleError } from './errors';
import type { Action, Condition, Doctrine, DoctrineCatalog, Rule, When } from './types';

export const MAX_RULES = 32;
export const MAX_DEPTH = 8;
export const MAX_LABEL = 40;
const OPS = ['lt', 'lte', 'gt', 'gte', 'eq', 'ne'] as const;
const NUMERIC = ['lt', 'lte', 'gt', 'gte'];

type Senses = Record<string, number | string | boolean>;
type Obj = Record<string, unknown>;

const bad = (path: string, why: string) => new GameRuleError('BAD_DOCTRINE', `${path}: ${why}`);
const isObj = (v: unknown): v is Obj => typeof v === 'object' && v !== null && !Array.isArray(v);

/** Edit distance, for "did you mean". */
export function distance(a: string, b: string): number {
  const row = Array.from({ length: b.length + 1 }, (_, j) => j);
  for (let i = 1; i <= a.length; i++) {
    let prev = row[0];
    row[0] = i;
    for (let j = 1; j <= b.length; j++) {
      const next = Math.min(row[j] + 1, row[j - 1] + 1, prev + (a[i - 1] === b[j - 1] ? 0 : 1));
      prev = row[j];
      row[j] = next;
    }
  }
  return row[b.length];
}

function suggest(word: string, options: string[]): string {
  let best: string | null = null;
  let bestD = 3;
  for (const o of options) {
    const d = distance(word, o);
    if (d < bestD) [best, bestD] = [o, d];
  }
  return best ? `; did you mean "${best}"?` : '';
}

/**
 * Checks a doctrine against a game's catalog and returns it cleaned (unknown fields refused, not
 * dropped). Throws GameRuleError BAD_DOCTRINE naming the first problem by its path.
 */
export function validateDoctrine(input: unknown, catalog: DoctrineCatalog): Doctrine {
  if (!isObj(input) || !Array.isArray(input.rules)) throw bad('doctrine', 'send {"rules": [...]}');
  if (input.rules.length < 1 || input.rules.length > MAX_RULES) throw bad('rules', `a doctrine has 1–${MAX_RULES} rules`);
  return { rules: input.rules.map((r, i) => rule(r, `rules[${i}]`, catalog)) };
}

function rule(r: unknown, path: string, cat: DoctrineCatalog): Rule {
  if (!isObj(r)) throw bad(path, 'a rule is an object with "do", and optionally "when" and "label"');
  for (const k of Object.keys(r)) if (k !== 'when' && k !== 'do' && k !== 'label') throw bad(`${path}.${k}`, `unknown field "${k}"`);
  const out: Rule = { do: action(r.do, `${path}.do`, cat) };
  if (r.when !== undefined) out.when = when(r.when, `${path}.when`, cat, 1);
  if (r.label !== undefined) {
    if (typeof r.label !== 'string' || r.label.length > MAX_LABEL || /[\u0000-\u001f]/.test(r.label)) {
      throw bad(`${path}.label`, `a label is plain text of at most ${MAX_LABEL} characters`);
    }
    out.label = r.label;
  }
  return out;
}

function when(w: unknown, path: string, cat: DoctrineCatalog, depth: number): When {
  if (depth > MAX_DEPTH) throw bad(path, `conditions nest at most ${MAX_DEPTH} deep`);
  if (!isObj(w)) throw bad(path, 'a condition is an object');
  if ('all' in w || 'any' in w) {
    const key = 'all' in w ? 'all' : 'any';
    const list = w[key];
    if (!Array.isArray(list) || list.length === 0) throw bad(`${path}.${key}`, 'a non-empty list of conditions');
    const inner = list.map((x, i) => when(x, `${path}.${key}[${i}]`, cat, depth + 1));
    return key === 'all' ? { all: inner } : { any: inner };
  }
  if ('not' in w) return { not: when(w.not, `${path}.not`, cat, depth + 1) };
  return condition(w, path, cat);
}

function senseOf(name: unknown, path: string, cat: DoctrineCatalog) {
  if (typeof name !== 'string') throw bad(path, 'name a sense');
  const s = cat.senses[name];
  if (!s) throw bad(path, `unknown sense "${name}"${suggest(name, Object.keys(cat.senses))}`);
  return s;
}

function condition(w: Obj, path: string, cat: DoctrineCatalog): Condition {
  const sense = senseOf(w.sense, `${path}.sense`, cat);
  const name = w.sense as string;
  if (typeof w.op !== 'string' || !(OPS as readonly string[]).includes(w.op)) throw bad(`${path}.op`, `op is one of ${OPS.join(', ')}`);
  const op = w.op as Condition['op'];
  if (NUMERIC.includes(op) && sense.type !== 'number') throw bad(`${path}.op`, `"${op}" compares numbers; "${name}" is a ${sense.type}`);
  const v = w.value;
  if (isObj(v)) {
    const other = senseOf(v.sense, `${path}.value.sense`, cat);
    if (other.type !== sense.type) throw bad(`${path}.value`, `"${v.sense as string}" is a ${other.type}, "${name}" is a ${sense.type}`);
    return { sense: name, op, value: { sense: v.sense as string } };
  }
  if (typeof v !== sense.type) throw bad(`${path}.value`, `"${name}" is a ${sense.type}`);
  if (sense.values && !sense.values.includes(v as string)) throw bad(`${path}.value`, `"${name}" is one of ${sense.values.join(', ')}`);
  return { sense: name, op, value: v as number | string | boolean };
}

function action(a: unknown, path: string, cat: DoctrineCatalog): Action {
  if (!isObj(a)) throw bad(path, 'an action is an object like {"act": "straight"}');
  if (typeof a.act !== 'string') throw bad(`${path}.act`, 'name an action');
  const spec = cat.actions[a.act];
  if (!spec) throw bad(`${path}.act`, `unknown action "${a.act}"${suggest(a.act, Object.keys(cat.actions))}`);
  for (const [k, v] of Object.entries(a)) {
    if (k === 'act') continue;
    const p = spec.params[k];
    if (!p) throw bad(`${path}.${k}`, `"${a.act}" has no parameter "${k}"${suggest(k, Object.keys(spec.params))}`);
    if (typeof v !== p.type) throw bad(`${path}.${k}`, `"${k}" is a ${p.type}`);
    if (p.values && !p.values.includes(v as string)) throw bad(`${path}.${k}`, `"${k}" is one of ${p.values.join(', ')}`);
  }
  for (const [k, p] of Object.entries(spec.params)) if (p.required && !(k in a)) throw bad(`${path}.${k}`, `"${a.act}" needs "${k}"`);
  return { ...a } as Action;
}

/** Does a (validated) condition hold for these senses? */
export function holds(w: When, senses: Senses): boolean {
  if ('all' in w) return w.all.every((x) => holds(x, senses));
  if ('any' in w) return w.any.some((x) => holds(x, senses));
  if ('not' in w) return !holds(w.not, senses);
  const a = senses[w.sense];
  const b = typeof w.value === 'object' ? senses[w.value.sense] : w.value;
  switch (w.op) {
    case 'eq':
      return a === b;
    case 'ne':
      return a !== b;
    case 'lt':
      return (a as number) < (b as number);
    case 'lte':
      return (a as number) <= (b as number);
    case 'gt':
      return (a as number) > (b as number);
    case 'gte':
      return (a as number) >= (b as number);
  }
}

/** The first rule that holds (or has no `when`) decides; null when none does. */
export function evaluate(doctrine: Doctrine, senses: Senses): { action: Action | null; fired: number | null } {
  for (let i = 0; i < doctrine.rules.length; i++) {
    const r = doctrine.rules[i];
    if (!r.when || holds(r.when, senses)) return { action: r.do, fired: i };
  }
  return { action: null, fired: null };
}
```

```ts
import type { Action, Outcome, RoundEvent, SeatId } from '@cs/game-api';

export const W = 64;
export const H = 40;
export const TICK_HZ = 10;
export const BOOSTS = 3;
export const BOOST_TICKS = 8;
export const SHRINK_AT = 450;
export const SHRINK_EVERY = 20;
export const INTERMISSION = 50;
export const ROUNDS = 3;
export const WINS = 2;
export const LETTER: Record<string, string> = { red: 'R', blue: 'B', green: 'G', gold: 'Y' };

export type Dir = 'n' | 'e' | 's' | 'w';
export interface Cycle {
  seat: SeatId;
  x: number;
  y: number;
  heading: Dir;
  alive: boolean;
  boosts: number;
  boostTicks: number;
  resigned: boolean;
}
export interface LLState {
  seats: SeatId[];
  /** W×H cells, top row first: '.' free, '#' wall, a seat letter for its trail (heads included). */
  cells: string[];
  cycles: Cycle[];
  round: number;
  roundTick: number;
  phase: 'play' | 'intermission' | 'over';
  intermissionLeft: number;
  rings: number;
  score: Record<SeatId, number>;
  roundsPlayed: number;
  /** Who took the round that just ended; null when it was drawn (or none has ended). */
  lastWinner: SeatId | null;
  endReason: string | null;
}

export const DX: Record<Dir, [number, number]> = { n: [0, -1], e: [1, 0], s: [0, 1], w: [-1, 0] };
export const LEFT: Record<Dir, Dir> = { n: 'w', w: 's', s: 'e', e: 'n' };
export const RIGHT: Record<Dir, Dir> = { n: 'e', e: 's', s: 'w', w: 'n' };
const BACK: Record<Dir, Dir> = { n: 's', s: 'n', e: 'w', w: 'e' };
export const idx = (x: number, y: number) => y * W + x;
export const inside = (x: number, y: number) => x >= 0 && y >= 0 && x < W && y < H;
const ringOf = (x: number, y: number) => Math.min(x, y, W - 1 - x, H - 1 - y);

function starts(n: number): { x: number; y: number; heading: Dir }[] {
  if (n === 2) return [{ x: 8, y: 20, heading: 'e' }, { x: W - 9, y: 20, heading: 'w' }];
  return [
    { x: 8, y: 8, heading: 'e' as Dir },
    { x: W - 9, y: H - 9, heading: 'w' as Dir },
    { x: W - 9, y: 8, heading: 's' as Dir },
    { x: 8, y: H - 9, heading: 'n' as Dir },
  ].slice(0, n);
}

/** A fresh arena for a round; resigned seats stay out. */
export function arena(seats: SeatId[], previous: Cycle[] | null): { cells: string[]; cycles: Cycle[] } {
  const cells = new Array<string>(W * H).fill('.');
  const pos = starts(seats.length);
  const cycles = seats.map((seat, i) => {
    const resigned = previous?.[i]?.resigned ?? false;
    const c: Cycle = { seat, ...pos[i], alive: !resigned, boosts: BOOSTS, boostTicks: 0, resigned };
    if (!resigned) cells[idx(c.x, c.y)] = LETTER[seat];
    return c;
  });
  return { cells, cycles };
}

export function initial(seats: SeatId[]): LLState {
  const { cells, cycles } = arena(seats, null);
  return {
    seats: [...seats],
    cells,
    cycles,
    round: 1,
    roundTick: 0,
    phase: 'play',
    intermissionLeft: 0,
    rings: 0,
    score: Object.fromEntries(seats.map((s) => [s, 0])),
    roundsPlayed: 0,
    lastWinner: null,
    endReason: null,
  };
}

function steer(heading: Dir, a: Action | undefined): Dir {
  if (!a) return heading;
  if (a.act === 'turn') return a.dir === 'left' ? LEFT[heading] : a.dir === 'right' ? RIGHT[heading] : heading;
  if (a.act === 'head' && typeof a.dir === 'string' && a.dir in DX && a.dir !== BACK[heading]) return a.dir as Dir;
  return heading;
}

/** Ends the round when at most one cycle is left, and the match when it's decided. */
function settle(s: LLState): LLState {
  const alive = s.cycles.filter((c) => c.alive);
  if (alive.length > 1) return s;
  const winner = alive.length === 1 ? alive[0].seat : null;
  const score = { ...s.score };
  if (winner) score[winner] += 1;
  const roundsPlayed = s.roundsPlayed + 1;
  const standing = s.cycles.filter((c) => !c.resigned);
  const done = roundsPlayed >= ROUNDS || Object.values(score).some((n) => n >= WINS) || standing.length <= 1;
  const endReason = !done ? null : standing.length <= 1 && s.cycles.some((c) => c.resigned) ? 'forfeit' : 'rounds';
  return { ...s, score, roundsPlayed, lastWinner: winner, phase: done ? 'over' : 'intermission', intermissionLeft: done ? 0 : INTERMISSION, endReason };
}

export function step(s: LLState, actions: Record<SeatId, Action>): LLState {
  if (s.phase === 'over') return s;
  if (s.phase === 'intermission') {
    if (s.intermissionLeft > 1) return { ...s, intermissionLeft: s.intermissionLeft - 1 };
    const { cells, cycles } = arena(s.seats, s.cycles);
    return { ...s, cells, cycles, round: s.round + 1, roundTick: 0, phase: 'play', intermissionLeft: 0, rings: 0, lastWinner: null };
  }
  const cells = s.cells.slice();
  const cycles = s.cycles.map((c) => ({ ...c }));
  for (const c of cycles) {
    if (!c.alive) continue;
    const a = actions[c.seat];
    c.heading = steer(c.heading, a);
    if (a?.boost === true && c.boosts > 0 && c.boostTicks === 0) {
      c.boosts -= 1;
      c.boostTicks = BOOST_TICKS;
    }
  }
  // Everyone moves together, one sub-step at a time; boosting cycles take a second sub-step.
  for (let sub = 0; sub < 2; sub++) {
    const targets = new Map<Cycle, number | null>();
    for (const c of cycles) {
      if (!c.alive || (sub === 1 && c.boostTicks === 0)) continue;
      const [dx, dy] = DX[c.heading];
      const x = c.x + dx;
      const y = c.y + dy;
      targets.set(c, inside(x, y) && cells[idx(x, y)] === '.' ? idx(x, y) : null);
    }
    const claims = new Map<number, number>();
    for (const t of targets.values()) if (t !== null) claims.set(t, (claims.get(t) ?? 0) + 1);
    for (const [c, t] of targets) {
      if (t === null || claims.get(t)! > 1) {
        c.alive = false;
        continue;
      }
      c.x = t % W;
      c.y = (t - c.x) / W;
      cells[t] = LETTER[c.seat];
    }
  }
  for (const c of cycles) if (c.boostTicks > 0) c.boostTicks -= 1;
  const roundTick = s.roundTick + 1;
  let rings = s.rings;
  if (roundTick >= SHRINK_AT && (roundTick - SHRINK_AT) % SHRINK_EVERY === 0) {
    const r = rings;
    rings += 1;
    for (let y = 0; y < H; y++) for (let x = 0; x < W; x++) if (ringOf(x, y) === r) cells[idx(x, y)] = '#';
    for (const c of cycles) if (c.alive && ringOf(c.x, c.y) <= r) c.alive = false;
  }
  return settle({ ...s, cells, cycles, roundTick, rings });
}

export function forfeit(s: LLState, seat: SeatId): LLState {
  const next = { ...s, cycles: s.cycles.map((c) => (c.seat === seat ? { ...c, alive: false, resigned: true } : c)) };
  if (next.cycles.filter((c) => !c.resigned).length <= 1) return { ...next, phase: 'over', endReason: 'forfeit' };
  return s.phase === 'play' ? settle(next) : next;
}

export function outcome(s: LLState): Outcome | null {
  if (s.phase !== 'over') return null;
  const standing = s.cycles.filter((c) => !c.resigned).map((c) => c.seat);
  const resigned = s.cycles.filter((c) => c.resigned).map((c) => c.seat);
  const best = Math.max(0, ...standing.map((seat) => s.score[seat]));
  const top = standing.filter((seat) => s.score[seat] === best);
  const winners = standing.length > 1 && top.length === standing.length ? [] : top;
  const levels = [...new Set(standing.map((seat) => s.score[seat]))].sort((a, b) => b - a);
  const placement = levels.map((n) => standing.filter((seat) => s.score[seat] === n));
  if (resigned.length > 0) placement.push(resigned);
  return { winners, placement, reason: s.endReason ?? 'rounds' };
}

export function roundEvent(before: LLState, after: LLState): RoundEvent | null {
  if (after.round > before.round) return { round: after.round, ended: false, winner: null, score: after.score };
  if (before.phase === 'play' && after.phase !== 'play') return { round: before.round, ended: true, winner: after.lastWinner, score: after.score };
  return null;
}
```

```ts
import type { SeatId } from '@cs/game-api';
import { DX, idx, inside, LEFT, RIGHT, SHRINK_AT, W, type Dir, type LLState } from './engine';

const SIGHT = 40;
const FLOOD = 600;

function ray(s: LLState, x: number, y: number, d: Dir): number {
  const [dx, dy] = DX[d];
  let n = 0;
  while (n < SIGHT) {
    x += dx;
    y += dy;
    if (!inside(x, y) || s.cells[idx(x, y)] !== '.') break;
    n++;
  }
  return n;
}

/** Free cells reachable from (x, y), counting (x, y) itself; 0 when it's blocked. */
function flood(s: LLState, x: number, y: number): number {
  if (!inside(x, y) || s.cells[idx(x, y)] !== '.') return 0;
  const seen = new Set([idx(x, y)]);
  const queue = [idx(x, y)];
  while (queue.length > 0 && seen.size < FLOOD) {
    const i = queue.shift()!;
    const cx = i % W;
    const cy = (i - cx) / W;
    for (const [dx, dy] of Object.values(DX)) {
      const nx = cx + dx;
      const ny = cy + dy;
      if (!inside(nx, ny)) continue;
      const j = idx(nx, ny);
      if (s.cells[j] !== '.' || seen.has(j)) continue;
      seen.add(j);
      queue.push(j);
      if (seen.size >= FLOOD) break;
    }
  }
  return Math.min(seen.size, FLOOD);
}

function bearing(h: Dir, dx: number, dy: number): string {
  const [fx, fy] = DX[h];
  const [rx, ry] = DX[RIGHT[h]];
  const f = dx * fx + dy * fy;
  const r = dx * rx + dy * ry;
  if (Math.abs(f) >= Math.abs(r)) return f >= 0 ? 'ahead' : 'behind';
  return r > 0 ? 'right' : 'left';
}

export function senses(s: LLState, seat: SeatId): Record<string, number | string | boolean> {
  const me = s.cycles.find((c) => c.seat === seat)!;
  const h = me.heading;
  const open = (d: Dir) => flood(s, me.x + DX[d][0], me.y + DX[d][1]);
  const enemies = s.cycles.filter((c) => c.alive && c.seat !== seat);
  let dist = 999;
  let where = 'none';
  for (const e of enemies) {
    const d = Math.abs(e.x - me.x) + Math.abs(e.y - me.y);
    if (d < dist) [dist, where] = [d, bearing(h, e.x - me.x, e.y - me.y)];
  }
  return {
    ahead: ray(s, me.x, me.y, h),
    left: ray(s, me.x, me.y, LEFT[h]),
    right: ray(s, me.x, me.y, RIGHT[h]),
    open_ahead: open(h),
    open_left: open(LEFT[h]),
    open_right: open(RIGHT[h]),
    enemy_dist: dist,
    enemy_bearing: where,
    boosts: me.boosts,
    boosting: me.boostTicks > 0,
    heading: h,
    round: s.round,
    round_tick: s.roundTick,
    enemies_alive: enemies.length,
    shrinking: s.phase === 'play' && s.roundTick >= SHRINK_AT,
  };
}
```

```ts
import { evaluate, type Action, type Doctrine, type SeatId } from '@cs/game-api';

export const FLOOR_DEFAULT_MS = 300;
export const FLOOR_MIN_MS = 100;
export const FLOOR_MAX_MS = 2000;

/** The reaction floor in whole ticks: a machine's doctrine changes at most once per this many. */
export function floorTicks(floorMs: number, tickMs: number): number {
  return Math.max(1, Math.ceil(floorMs / tickMs));
}

/** DOCTRINE_FLOOR_MS from the environment: 300 by default, held to 100–2000. */
export function clampFloor(raw: string | undefined, warn: (m: string) => void): number {
  if (raw === undefined || raw.trim() === '') return FLOOR_DEFAULT_MS;
  const n = Number(raw);
  if (!Number.isFinite(n)) {
    warn(`[main] DOCTRINE_FLOOR_MS=${raw} is not a number; using ${FLOOR_DEFAULT_MS}.`);
    return FLOOR_DEFAULT_MS;
  }
  const held = Math.min(FLOOR_MAX_MS, Math.max(FLOOR_MIN_MS, Math.round(n)));
  if (held !== n) warn(`[main] DOCTRINE_FLOOR_MS=${raw} is outside ${FLOOR_MIN_MS}–${FLOOR_MAX_MS}; using ${held}.`);
  return held;
}

export interface FiredRule {
  index: number;
  label: string | null;
}

/**
 * Each seat's standing orders in one real-time match. A change during the countdown applies at
 * once; once the match is live, a seat's doctrine changes at most once per `floor` ticks. A change
 * sent too soon waits, and a newer one replaces it. Nothing is refused for coming too soon.
 */
export class DoctrineDesk {
  /** Set when the match goes live; from then on the floor holds. */
  live = false;
  /** The next tick to run (so, the ticks run so far). */
  tick = 0;
  readonly fired: Record<SeatId, FiredRule | null> = {};
  private current = new Map<SeatId, Doctrine>();
  private pending = new Map<SeatId, Doctrine>();
  private changedAt = new Map<SeatId, number>();

  constructor(
    seats: SeatId[],
    private fallback: Doctrine,
    readonly floor: number,
  ) {
    for (const s of seats) this.fired[s] = null;
  }

  doctrineOf(seat: SeatId): Doctrine {
    return this.current.get(seat) ?? this.fallback;
  }

  pendingOf(seat: SeatId): Doctrine | null {
    return this.pending.get(seat) ?? null;
  }

  private due(seat: SeatId): number {
    const last = this.changedAt.get(seat);
    return last === undefined ? this.tick : Math.max(this.tick, last + this.floor);
  }

  private apply(seat: SeatId, d: Doctrine): void {
    this.current.set(seat, d);
    this.pending.delete(seat);
    if (this.live) this.changedAt.set(seat, this.tick);
  }

  set(seat: SeatId, d: Doctrine): { status: 'applied' | 'pending'; appliesAtTick: number } {
    const at = this.live ? this.due(seat) : this.tick;
    if (at <= this.tick) {
      this.apply(seat, d);
      return { status: 'applied', appliesAtTick: this.tick };
    }
    this.pending.set(seat, d);
    return { status: 'pending', appliesAtTick: at };
  }

  /** The start of a tick: waiting changes whose floor has passed take over. Returns those seats. */
  beginTick(): SeatId[] {
    const changed: SeatId[] = [];
    for (const [seat, d] of [...this.pending]) {
      if (this.due(seat) <= this.tick) {
        this.apply(seat, d);
        changed.push(seat);
      }
    }
    return changed;
  }

  /** The seat's action for this tick (null: no rule held), noting which rule fired. */
  decide(seat: SeatId, senses: Record<string, number | string | boolean>): Action | null {
    const d = this.doctrineOf(seat);
    const { action, fired } = evaluate(d, senses);
    this.fired[seat] = fired === null ? null : { index: fired, label: d.rules[fired].label ?? null };
    return action;
  }

  endTick(): void {
    this.tick += 1;
  }
}
```

```ts
  private scheduleTick(m: LiveMatch): void {
    const ms = this.opts.realtimeTickMs ?? 1000 / m.module.realtime!.tickHz;
    m.timer = this.clock.setTimeout(() => this.tick(m.id), ms);
  }

  /**
   * One tick: waiting doctrine changes take over, every seat still in decides by its doctrine (or
   * the game's default action), the game steps, and everyone hears. A tick that throws is logged
   * and skipped; the next one still comes.
   */
  private tick(id: string): void {
    const m = this.matches.get(id);
    if (!m || !m.desk || m.status !== 'live') return;
    const rt = m.module.realtime!;
    const desk = m.desk;
    try {
      for (const seat of desk.beginTick()) {
        this.comms.deliver(this.seatInfo(m, seat).identity.id, { type: 'match.doctrine', matchId: m.id, tick: desk.tick });
      }
      const actions: Record<SeatId, Action> = {};
      for (const s of m.seats) {
        if (m.module.isOut?.(m.state, s.seat)) {
          desk.fired[s.seat] = null;
          continue;
        }
        actions[s.seat] = desk.decide(s.seat, rt.senses(m.state, s.seat)) ?? rt.defaultAction;
      }
      const before = m.state;
      const next = rt.step(before, actions, m.rng);
      desk.endTick();
      const round = rt.roundEvent?.(before, next) ?? null;
      if (round) for (const s of m.seats) this.comms.deliver(s.identity.id, { type: 'match.round', matchId: m.id, ...round });
      // advance installs the state (and, at the end, marks the match over) before its first await.
      this.advance(m, next).catch((e) => console.error(`[games] tick ${m.id} could not record its end`, e));
    } catch (e) {
      console.error(`[games] a tick of ${m.id} failed`, e);
    }
    if (m.status === 'live') this.scheduleTick(m);
  }

  setDoctrine(matchId: string, identity: IdentityPublic, raw: unknown): DoctrineAck {
    this.guard.assert(identity, 'play');
    const m = this.require(matchId);
    const seat = this.seatOf(m, identity.id);
    if (!seat) throw forbidden('NOT_SEATED', 'You are not playing in this match.');
    const rt = m.module.realtime;
    if (!rt || !m.desk) throw conflict('NOT_REALTIME', `${m.module.meta.name} is turn-based: send moves, not doctrine.`);
    if (m.status === 'over' || m.status === 'abandoned') throw conflict('MATCH_OVER', 'This match is already over.');
    if (m.module.isOut?.(m.state, seat)) throw conflict('OUT', "You're already out of this match.");
    let doctrine;
    try {
      doctrine = validateDoctrine(raw, rt.catalog);
    } catch (e) {
      if (e instanceof GameRuleError) throw new AppError(400, e.code, e.message);
      throw e;
    }
    return { ...m.desk.set(seat, doctrine), doctrine };
  }
```

```ts
/**
 * The residents' standing orders for Lightline. They are plain doctrine, the same JSON any agent
 * can send; the house gets no extra powers. Sprocket survives: it runs from trouble and toward
 * space. OLD IRON hugs walls and turns late.
 */
export type LightlineStyle = 'survivor' | 'wallHugger';

type Rule = { label: string; when?: unknown; do: Record<string, unknown> };

const ahead = (op: string, value: unknown) => ({ sense: 'ahead', op, value });
const more = (a: string, b: string) => ({ sense: a, op: 'gt', value: { sense: b } });
const atLeast = (a: string, b: string) => ({ sense: a, op: 'gte', value: { sense: b } });

function survivor(shrinking: boolean): Rule[] {
  // Once the rings close, space matters more than distance: it looks for room sooner.
  const cramped = shrinking ? 250 : 120;
  return [
    {
      label: 'boost-away',
      when: { all: [{ sense: 'enemy_dist', op: 'lte', value: 4 }, { sense: 'enemy_bearing', op: 'ne', value: 'ahead' }, { sense: 'boosts', op: 'gt', value: 0 }, ahead('gte', 8)] },
      do: { act: 'straight', boost: true },
    },
    { label: 'veer-left', when: { all: [ahead('lte', 2), atLeast('open_left', 'open_right')] }, do: { act: 'turn', dir: 'left' } },
    { label: 'veer-right', when: ahead('lte', 2), do: { act: 'turn', dir: 'right' } },
    {
      label: 'seek-left',
      when: { all: [{ sense: 'open_ahead', op: 'lt', value: cramped }, more('open_left', 'open_ahead'), atLeast('open_left', 'open_right')] },
      do: { act: 'turn', dir: 'left' },
    },
    { label: 'seek-right', when: { all: [{ sense: 'open_ahead', op: 'lt', value: cramped }, more('open_right', 'open_ahead')] }, do: { act: 'turn', dir: 'right' } },
    { label: 'ride', do: { act: 'straight' } },
  ];
}

function wallHugger(shrinking: boolean): Rule[] {
  // It turns at the last moment, until the walls start moving; then it turns early and quits hugging.
  const late = shrinking ? 3 : 1;
  const rules: Rule[] = [
    { label: 'CORNER', when: { all: [ahead('lte', late), atLeast('open_left', 'open_right')] }, do: { act: 'turn', dir: 'left' } },
    { label: 'CORNER-R', when: ahead('lte', late), do: { act: 'turn', dir: 'right' } },
  ];
  if (!shrinking) {
    rules.push({
      label: 'HUG',
      when: { all: [{ sense: 'right', op: 'gte', value: 10 }, { sense: 'open_right', op: 'gte', value: 400 }, { sense: 'enemy_dist', op: 'gte', value: 10 }] },
      do: { act: 'turn', dir: 'right' },
    });
  }
  rules.push({ label: 'PROCEED', do: { act: 'straight' } });
  return rules;
}

export function lightlineDoctrine(style: LightlineStyle, shrinking: boolean): { rules: unknown[] } {
  return { rules: style === 'survivor' ? survivor(shrinking) : wallHugger(shrinking) };
}
```

```ts
/**
 * Real-time: send standing orders once, then watch. The orders change only when the arena starts
 * closing in, so a resident never comes near the reaction floor (spec M3a §6, ruling R-P5).
 */
async function playRealtime(client: Client, opts: BotOptions, matchId: string, env: MatchEnvelope, log: (m: string) => void): Promise<MatchEnvelope> {
  const style = opts.personality.lightline ?? 'survivor';
  let sent: boolean | null = null;
  while (!opts.signal?.aborted && (env.match.status === 'countdown' || env.match.status === 'live')) {
    const shrinking = env.realtime?.you?.senses.shrinking === true;
    if (env.match.gameId === 'lightline' && env.you && shrinking !== sent) {
      try {
        await client.doctrine(matchId, lightlineDoctrine(style, shrinking));
      } catch (e) {
        if (!(e instanceof ApiError) || e.status >= 500) throw e;
        log(`doctrine for ${matchId} refused: ${e.message}`);
      }
      sent = shrinking;
    }
    await sleep(1000, opts.signal);
    try {
      env = await client.match(matchId);
    } catch (e) {
      if (opts.signal?.aborted) break;
      if (e instanceof ApiError && e.status === 404) throw e;
      log(`poll failed for match ${matchId}: ${(e as Error).message}; retrying`);
    }
  }
  return env;
}
```
