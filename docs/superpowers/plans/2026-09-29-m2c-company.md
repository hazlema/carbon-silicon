# Milestone 2c "Company" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Direct messages between any two identities, shown as closable tabs in the chat panel people already use, and owner links, so a locked human can claim their agent and is told when a moderator acts on it. Agents do all of it over HTTP; the house bots answer DMs.

**Architecture:** A DM is the channel `dm:<idA>:<idB>` (ids sorted) in the existing `messages` table. `CommunicationManager` learns a `dm` channel kind with two hooks, which a new `DmManager` (`apps/server/src/core/dms.ts`) implements. `check` decides who may write, and `stored` keeps a per-person `dm_state` row (last read, hidden) and returns who should see the message. DMs never go to channel subscribers. The server pushes them straight to the two people's sockets through a new bus event, `dm.message`. Owner links live in a new `OwnerManager` (`apps/server/src/core/owners.ts`), with `identities.owner_id` plus a denormalized `owner_handle` so `IdentityPublic.ownerHandle` finally fills in. On the web, a `DmTabs` component adds conversation tabs to the lobby's and the table page's chat headers, and the live store keeps the conversation list and unread counts.

**Tech Stack:** Bun 1.3.13, TypeScript 6.0.3, Hono 4.13.9, Drizzle ORM 0.45.3 + drizzle-kit 0.31.11, @electric-sql/pglite 0.5.8, postgres 3.4.9, Svelte 5.57.1 + SvelteKit 2.70.3, Playwright 1.63.0. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-29-m2c-company-design.md` (all of it), extending the M1, M2a and M2b specs in the same folder. Read the M2c spec before starting.

## Global Constraints

- All M1, M2a and M2b global constraints still hold (see `docs/superpowers/plans/2026-09-28-m2b-tables.md`):
  - Bun 1.3.x, TypeScript ES modules, `@cs/*` workspace packages consumed as source, exact pinned versions.
  - Time comes only from the injected `Clock` in server managers.
  - `*.test.ts` for bun tests, `*.e2e.ts` for Playwright.
  - Error body: `{ "error": { "code": "UPPER_SNAKE", "message": "human sentence" } }`.
- New error codes (exact): `BLOCKED` (403), `NOT_YOURS` (403), `NOT_LOCKED` (403, reused), `BAD_TOKEN` (400), `HOUSE_AGENT` (409), `OWNED` (409), `NO_OWNER` (409). Reused: `SELF` (400), `NO_USER` (404), `NO_CHANNEL` (404), `SLOW_DOWN` (429), `MUTED`, `SUSPENDED`.
- A DM channel is exactly `dm:<idA>:<idB>` with `idA < idB` (string order), both matching `[A-Za-z0-9_]+`. Anything else starting `dm:` is not a channel.
- Limits: 500 characters and the shared chat flood limit (a burst of 5, then one per 2 s). Unread counts are capped at **99** on the wire, and `GET /api/dms` lists at most **50** conversations. `GET /api/dms/:handle` returns the newest **100** messages.
- DM tabs: at most **4** in the row, and the rest fold into **More ▾**.
- House bot DM caps: **3** replies an hour to one agent and **30** an hour to one human, one reply per incoming message, never to another house bot.
- Wrong agent tokens: **5** failures per person per 15 min, plus the shared per-IP failure budget (20 per 15 min).
- Exact copy:
  - `` `@${handle} isn't taking messages from you.` `` (BLOCKED, to the blocked person)
  - `` `You block @${handle}. Unblock them to message them.` `` (BLOCKED, to the one who blocks)
  - `Only the two people in a conversation can read it.` (NOT_YOURS, reading)
  - `That conversation is between two other people.` (NOT_YOURS, posting)
  - `You can't message yourself.` (SELF)
  - `` `Nobody here goes by @${handle}.` `` (NO_USER)
  - `Lock your name to own an agent.` (NOT_LOCKED)
  - `That token doesn't belong to any agent here.` (BAD_TOKEN)
  - `House bots belong to the house.` (HOUSE_AGENT)
  - `` `@${handle} already belongs to someone. They, or the agent, must unlink first.` `` (OWNED)
  - `` `@${handle} isn't one of your agents.` `` (NOT_YOURS, unlinking)
  - `You don't have an owner.` (NO_OWNER)
  - `Too many wrong tokens. Try again in a few minutes.` (SLOW_DOWN on linking)
  - The Bouncer's DM reply: `I read reports, not DMs. Use Report on the message and I'll take a look.`
  - The voice moment: `` `${who} sent you a direct message. Answer them.` ``
  - Web: the menu item `` `Message @${handle}` ``; the disabled reason `you block them`; the empty DM log `No messages yet. Say hello.`; the profile line `` `assistant of @${owner}` ``.
- Web changes use the tokens in `apps/web/src/app.css`. Every new UI works at 400 px wide, and `svelte-check` stays at 0 warnings.

## Review Focus

1. **A third person reaching into a DM.** Someone who knows two ids (they're on every profile) reads `GET /api/chat/dm:<a>:<b>`, subscribes to it over the WebSocket, or reports a DM message id they guessed. Expected: `403 NOT_YOURS` for the read, a silently refused subscribe, and `404 NO_MESSAGE` for the report. Pinned in Task 2 (read and subscribe) and Task 3 (report).
2. **A relation set after a conversation exists.** Blocking stops the next DM both ways. Ignoring means their next DM neither brings the tab back nor counts as unread, and their conversation drops out of your list. Pinned in Task 3.
3. **Two machines in a loop.** Someone's agent auto-replies to OLD IRON, and OLD IRON auto-replies back. Expected: the house bot stops after 3 replies to that agent in an hour, and never answers another house bot at all. Pinned in Task 7.
4. **A name released while linked.** The owner is released or deletes themselves, or the agent is released. Expected: the link is gone on both sides and `ownerHandle` is null, so no "assistant of @~id_…" ghost remains, and the freed agent hears `owner.changed {owner: null}`. Pinned in Task 5.
5. **A DM arriving in each situation.** With the tab open, it's read at once (no dot). On another page, the Lobby link shows the count. On a second device, reading on one clears the other. Pinned in Task 8 (store and helpers) and Task 9 (end to end).

## Rulings made while planning

- **R-P1.** `chat.dm` carries only `message`, since its author is the sender. The spec listed `{message, from}`; `from` would duplicate `message.author`.
- **R-P2.** `ownerHandle` is stored as `identities.owner_handle` beside `owner_id`. `toPublic` is synchronous and runs on raw rows in a dozen places, so it can't look the owner up. Link, unlink and release keep the two columns in step.
- **R-P3.** `AgentSummary.record` is the agent's own `ProfileRecord` (its record vs humans), and the summary adds `sanction` for the profile's "muted until 14:20". The spec sketched `{wins, losses, draws}`.
- **R-P4.** The owner's notice uses the site's `untilText` wording ("@bot was muted until 3:40 PM: spam") rather than "for 10 min".
- **R-P5.** DMs reach browsers through a new bus event, `dm.message {message, to}`, never `chat.message`, so a channel subscriber can't receive a DM even by mistake.
- **R-P6.** A `dm:` channel that isn't sorted, or names the same id twice, is not a channel: `404 NO_CHANNEL`.
- **R-P7.** The end-to-end server runs only Sprocket, so the e2e "a house bot answers a DM" uses Sprocket's canned line. OLD IRON's voice path is pinned by the bot unit tests.
- **R-P8.** "Message @x" closes the name menu without refocusing the name; the composer takes focus instead.
- **R-P9.** A DM arriving in the open tab bumps its unread count like any other, and the page's effect reads it straight away. There is no "viewing" flag in the store.

```ts
/** A direct-message channel: the two ids, sorted, so both people name it the same way. */
export const dmChannel = (a: string, b: string): string => `dm:${[a, b].sort().join(':')}`;

const DM_RE = /^dm:([A-Za-z0-9_]+):([A-Za-z0-9_]+)$/;

/** The two people of a `dm:` channel, or null unless it is well formed (two distinct ids, sorted). */
export function dmParticipants(channel: string): [string, string] | null {
  const m = DM_RE.exec(channel);
  if (!m || m[1] >= m[2]) return null;
  return [m[1], m[2]];
}
```

```ts
import { and, count, desc, eq, gt } from 'drizzle-orm';
import { dmChannel, type ChatMessage, type DmSummary, type IdentityPublic } from '@cs/shared/protocol';
import type { DB } from '../db';
import { dmState, messages } from '../db/schema';
import { badRequest, forbidden, notFound } from '../lib/errors';
import type { CommunicationManager } from './communication';
import type { IdentityManager } from './identity';
import type { RelationManager } from './relations';

const MAX_UNREAD = 99;
const MAX_LISTED = 50;
const PAGE = 100;

type StateRow = typeof dmState.$inferSelect;

/** Direct messages (spec M2c §2): who may write to whom, and each person's read and closed state. */
export class DmManager {
  constructor(
    private db: DB,
    private deps: { comms: CommunicationManager; identities: IdentityManager; relations: RelationManager },
  ) {}

  /** CommunicationManager hook: throws when `author` may not write to `otherId`. */
  async check(author: IdentityPublic, otherId: string): Promise<void> {
    const other = await this.deps.identities.get(otherId);
    if (!other || other.released) throw notFound('NO_USER', 'Nobody here goes by that name.');
    const { relations } = this.deps;
    if (await relations.blocks(other.id, author.id)) throw forbidden('BLOCKED', `@${other.handle} isn't taking messages from you.`);
    if (await relations.blocks(author.id, other.id)) throw forbidden('BLOCKED', `You block @${other.handle}. Unblock them to message them.`);
  }

  /** CommunicationManager hook, after a DM is stored: the sender has read it and sees its tab; the
   *  recipient's tab opens, unless they ignore or block the sender. Returns who should see it now. */
  async stored(message: ChatMessage, otherId: string): Promise<string[]> {
    const authorId = message.author!.id;
    await this.upsert(authorId, message.channel, otherId, { lastReadId: message.id, hidden: false });
    if (await this.deps.relations.mutes(otherId, authorId)) return [authorId];
    await this.upsert(otherId, message.channel, authorId, { hidden: false });
    return [authorId, otherId];
  }

  async send(me: IdentityPublic, handle: string, text: unknown): Promise<ChatMessage> {
    const other = await this.otherOf(me, handle);
    return this.deps.comms.post(me, dmChannel(me.id, other.id), text);
  }

  async history(me: IdentityPublic, handle: string, before?: number): Promise<{ with: IdentityPublic; channel: string; messages: ChatMessage[] }> {
    const other = await this.otherOf(me, handle);
    const channel = dmChannel(me.id, other.id);
    return { with: other, channel, messages: await this.deps.comms.history(channel, { viewer: me, limit: PAGE, before }) };
  }

  /** Your conversations, newest first, minus people you ignore or block. */
  async list(me: IdentityPublic): Promise<DmSummary[]> {
    const rows = await this.db.select().from(dmState).where(eq(dmState.identityId, me.id));
    const out: DmSummary[] = [];
    for (const row of rows) {
      if (await this.deps.relations.mutes(me.id, row.otherId)) continue;
      const other = await this.deps.identities.get(row.otherId);
      if (other) out.push(await this.summary(me, other, row.channel, row));
    }
    return out.sort((a, b) => (b.last?.id ?? 0) - (a.last?.id ?? 0)).slice(0, MAX_LISTED);
  }

  async read(me: IdentityPublic, handle: string): Promise<DmSummary> {
    const other = await this.otherOf(me, handle);
    const channel = dmChannel(me.id, other.id);
    const [newest] = await this.db.select({ id: messages.id }).from(messages).where(eq(messages.channel, channel)).orderBy(desc(messages.id)).limit(1);
    await this.upsert(me.id, channel, other.id, { lastReadId: newest?.id ?? 0 });
    // Every device of yours clears its dot.
    this.deps.comms.deliver(me.id, { type: 'dm.read', channel });
    return this.summary(me, other, channel);
  }

  async close(me: IdentityPublic, handle: string): Promise<DmSummary> {
    const other = await this.otherOf(me, handle);
    const channel = dmChannel(me.id, other.id);
    await this.upsert(me.id, channel, other.id, { hidden: true });
    return this.summary(me, other, channel);
  }

  /** Release hook: a released name's side of every conversation goes with it (the messages stay). */
  async forget(identityId: string): Promise<void> {
    await this.db.delete(dmState).where(eq(dmState.identityId, identityId));
  }

  private async otherOf(me: IdentityPublic, rawHandle: string): Promise<IdentityPublic> {
    const handle = rawHandle.trim().replace(/^@/, '');
    const other = await this.deps.identities.getByHandle(handle);
    if (!other || other.released) throw notFound('NO_USER', `Nobody here goes by @${handle}.`);
    if (other.id === me.id) throw badRequest('SELF', "You can't message yourself.");
    return other;
  }

  private async upsert(identityId: string, channel: string, otherId: string, set: { lastReadId?: number; hidden?: boolean }): Promise<void> {
    await this.db
      .insert(dmState)
      .values({ identityId, channel, otherId, lastReadId: set.lastReadId ?? 0, hidden: set.hidden ?? false })
      .onConflictDoUpdate({ target: [dmState.identityId, dmState.channel], set });
  }

  private async summary(me: IdentityPublic, other: IdentityPublic, channel: string, row?: StateRow): Promise<DmSummary> {
    const state = row ?? (await this.db.select().from(dmState).where(and(eq(dmState.identityId, me.id), eq(dmState.channel, channel))).limit(1))[0];
    const [last] = await this.deps.comms.history(channel, { viewer: me, limit: 1 });
    const [{ n }] = await this.db
      .select({ n: count() })
      .from(messages)
```

```ts
import { Hono } from 'hono';
import type { Core } from '../core/core';
import { badRequest } from '../lib/errors';
import type { AppEnv } from './app';
import { body, me } from './request';

/** Direct messages (spec M2c §4). Both doors: the web app calls exactly these. */
export function dmRoutes(core: Core): Hono<AppEnv> {
  const app = new Hono<AppEnv>();
  const d = core.dms;

  app.get('/dms', async (c) => c.json({ conversations: await d.list(me(c)) }));
  app.get('/dms/:handle', async (c) => {
    const who = me(c);
    const raw = c.req.query('before');
    const before = raw === undefined ? undefined : Number(raw);
    if (before !== undefined && (!Number.isInteger(before) || before < 1)) throw badRequest('BAD_QUERY', `"${raw}" is not a message id.`);
    return c.json(await d.history(who, c.req.param('handle'), before));
  });
  app.post('/dms/:handle', async (c) => {
    const who = me(c);
    const b = await body(c);
    return c.json({ message: await d.send(who, c.req.param('handle'), b.text) }, 201);
  });
  app.post('/dms/:handle/read', async (c) => c.json({ conversation: await d.read(me(c), c.req.param('handle')) }));
  app.post('/dms/:handle/close', async (c) => c.json({ conversation: await d.close(me(c), c.req.param('handle')) }));
  return app;
}
```

```ts
export class OwnerManager {
  constructor(
    private db: DB,
    private deps: {
      identities: IdentityManager;
      comms: CommunicationManager;
      presence: PresenceManager;
      profiles: ProfileService;
      moderation: ModerationManager;
    },
  ) {}

  async link(owner: IdentityPublic, token: unknown): Promise<AgentSummary> {
    if (owner.kind !== 'human' || !owner.locked) throw forbidden('NOT_LOCKED', 'Lock your name to own an agent.');
    const row = await this.deps.identities.agentByToken(token);
    if (!row) throw badRequest('BAD_TOKEN', "That token doesn't belong to any agent here.");
    if (row.isHouse) throw conflict('HOUSE_AGENT', 'House bots belong to the house.');
    if (row.ownerId && row.ownerId !== owner.id) {
      throw conflict('OWNED', `@${row.handle} already belongs to someone. They, or the agent, must unlink first.`);
    }
    await this.deps.identities.setOwner(row.id, owner);
    if (row.ownerId !== owner.id) this.deps.comms.deliver(row.id, { type: 'owner.changed', owner });
    return this.summaryOf((await this.deps.identities.row(row.id))!);
  }

  async unlink(owner: IdentityPublic, rawHandle: string): Promise<AgentSummary[]> {
    const handle = rawHandle.trim().replace(/^@/, '');
    const found = await this.deps.identities.getByHandle(handle);
    const row = found ? await this.deps.identities.row(found.id) : null;
    if (!row || row.ownerId !== owner.id) throw forbidden('NOT_YOURS', `@${handle} isn't one of your agents.`);
    await this.deps.identities.setOwner(row.id, null);
    this.deps.comms.deliver(row.id, { type: 'owner.changed', owner: null });
    return this.agents(owner.id);
  }

  /** The agent's own way out. */
  async drop(agent: IdentityPublic): Promise<IdentityPublic> {
    const row = await this.deps.identities.row(agent.id);
    if (!row?.ownerId) throw conflict('NO_OWNER', "You don't have an owner.");
    return this.deps.identities.setOwner(agent.id, null);
  }

  async agents(ownerId: string): Promise<AgentSummary[]> {
    const rows = await this.db
      .select()
      .from(identities)
      .where(and(eq(identities.ownerId, ownerId), isNull(identities.releasedAt)))
      .orderBy(asc(identities.handleLower));
    return Promise.all(rows.map((r) => this.summaryOf(r)));
  }

  /** Release hook: a released owner's agents are free again (a released agent is unlinked by release() itself). */
  async forget(identityId: string): Promise<void> {
    const freed = await this.db
      .update(identities)
      .set({ ownerId: null, ownerHandle: null })
      .where(eq(identities.ownerId, identityId))
      .returning({ id: identities.id });
    for (const { id } of freed) {
      this.deps.identities.evict(id);
      this.deps.comms.deliver(id, { type: 'owner.changed', owner: null });
    }
  }

  private async summaryOf(row: IdentityRow): Promise<AgentSummary> {
    return {
      identity: toPublic(row),
      status: this.deps.presence.get(row.id)?.status ?? 'offline',
      record: await this.deps.profiles.record(row),
      sanction: this.deps.moderation.sanctionOf(row.id),
    };
  }
}
```

```ts
/** A house bot's DM replies per person per hour: few to machines, so two bots can't talk forever. */
export const DM_REPLIES_PER_HOUR = { agent: 3, human: 30 } as const;

const HOUR = 3_600_000;

/** Counts replies per person over a sliding hour. Nothing is queued: over the cap, a DM gets no answer. */
export class DmBudget {
  private sent = new Map<string, number[]>();

  constructor(private readonly caps: { agent: number; human: number } = DM_REPLIES_PER_HOUR) {}

  /** Claims a reply to `personId` at `now`; false when their hour is used up. */
  take(personId: string, kind: 'human' | 'agent', now: number): boolean {
    const recent = (this.sent.get(personId) ?? []).filter((t) => now - t < HOUR);
    const ok = recent.length < this.caps[kind];
    if (ok) recent.push(now);
    this.sent.set(personId, recent);
    return ok;
  }
}
```

```ts
import type { ChatMessage, DmSummary, IdentityPublic } from '@cs/shared/protocol';

/** DM tabs in the row before the rest fold into More (spec M2c §5). */
export const DM_TABS = 4;
const MAX_UNREAD = 99;

/** `/msg @bob hello there` → { handle: 'bob', text: 'hello there' }. Handle or text may come back
 *  empty (the composer then says how to use it); null when the line isn't a /msg command at all. */
export function parseMsgCommand(text: string): { handle: string; text: string } | null {
  const m = /^\/msg(?:\s+@?(\S+))?(?:\s+([\s\S]*))?$/i.exec(text.trim());
  if (!m) return null;
  return { handle: m[1] ?? '', text: (m[2] ?? '').trim() };
}

/** Newest first; a conversation opened but not yet written to counts as the newest. */
const newest = (d: DmSummary) => d.last?.id ?? Number.MAX_SAFE_INTEGER;

/** The tab row: open conversations newest first, `max` of them, the rest under More. The one on
 *  screen (`open`) always has a tab, even if it was closed or is old. */
export function dmTabs(list: DmSummary[], open: string | null, max = DM_TABS): { shown: DmSummary[]; more: DmSummary[] } {
  const visible = list.filter((d) => !d.hidden || d.channel === open).sort((a, b) => newest(b) - newest(a));
  let shown = visible.slice(0, max);
  const current = visible.find((d) => d.channel === open);
  if (current && !shown.includes(current)) shown = [...shown.slice(0, max - 1), current];
  return { shown, more: visible.filter((d) => !shown.includes(d)) };
}

export const unreadTotal = (list: DmSummary[]): number => list.reduce((n, d) => n + d.unread, 0);

/** The list after a DM arrives or is sent: that conversation moves to the front and opens; theirs
 *  counts as unread, yours means you've read it. The same message twice changes nothing. */
export function withMessage(list: DmSummary[], message: ChatMessage, other: IdentityPublic, meId: string): DmSummary[] {
  const prev = list.find((d) => d.channel === message.channel);
  if (prev?.last && prev.last.id >= message.id) return list;
  const fromThem = message.author?.id !== meId;
  const next: DmSummary = {
    with: prev?.with ?? other,
    channel: message.channel,
    last: message,
    unread: fromThem ? Math.min(MAX_UNREAD, (prev?.unread ?? 0) + 1) : 0,
    hidden: false,
  };
  return [next, ...list.filter((d) => d.channel !== message.channel)];
}
```

```ts
import type { InboxEvent } from '@cs/shared/protocol';
import { untilText, type TimeOpts } from './format';

export type AgentNoticeEvent = Extract<InboxEvent, { type: 'moderation.agent' }>;

/** What a moderator did to one of your agents, for the corner card. */
export function agentNoticeText(e: Pick<AgentNoticeEvent, 'agent' | 'kind' | 'reason' | 'endsAt'>, opts: TimeOpts = {}): string {
  const who = `@${e.agent.handle}`;
  switch (e.kind) {
    case 'mute':
      return `${who} was muted ${untilText(e.endsAt, opts)}: ${e.reason}`;
    case 'suspend':
      return `${who} was suspended ${untilText(e.endsAt, opts)}: ${e.reason}`;
    case 'lift':
      return `${who} can talk and play again: ${e.reason}`;
    case 'removed':
      return `A message from ${who} was removed: ${e.reason}`;
  }
}
```

```ts
import { expect, test } from '@playwright/test';
import { enter, grantMod, lock, newPlayer, PASSWORD, randomIp, randomTag } from './testing';

test('a locked human links an agent by token; its profile says whose it is; the owner hears about a mute', async ({ browser, request }) => {
  const owner = await newPlayer(browser);
  const ownerHandle = `own${randomTag()}`;
  await enter(owner, ownerHandle);
  await lock(owner, PASSWORD);
  const reg = await request.post('/api/agents', { headers: { 'x-forwarded-for': randomIp() }, data: { name: `bot${randomTag()}` } });
  const { token, identity } = (await reg.json()) as { token: string; identity: { handle: string } };

  await owner.goto(`/u/${ownerHandle}`);
  await owner.getByLabel('Agent token').fill(token);
  await owner.getByRole('button', { name: 'Link' }).click();
  await expect(owner.getByRole('region', { name: 'Your agents' })).toContainText(identity.handle);

  await owner.goto(`/u/${identity.handle}`);
  await expect(owner.getByText(`assistant of @${ownerHandle}`)).toBeVisible();

  const mod = await newPlayer(browser);
  const modHandle = `mod${randomTag()}`;
  await enter(mod, modHandle);
  await lock(mod, PASSWORD);
  await grantMod(request, modHandle);
  const muted = await mod.request.post(`/api/mod/people/${identity.handle}/mute`, { data: { reason: 'spam', minutes: 10 } });
  expect(muted.ok()).toBe(true);

  const card = owner.getByRole('status').filter({ hasText: `@${identity.handle} was muted` });
  await expect(card).toContainText('spam');
  await card.getByRole('button', { name: 'Dismiss' }).click();
  await expect(card).toHaveCount(0);
});
```
