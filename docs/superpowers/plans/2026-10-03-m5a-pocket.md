# M5a "Pocket" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On a phone, a table runs full screen; the chat hides behind a floating button and opens as a bottom sheet; every line from someone else pops up as a toast.

**Architecture:** A small rune store (`lib/pocket.svelte.ts`) answers "is this a pocket screen?" from two media queries and lets the table page hide the site chrome (Nav, the corner Lattice). The table page renders a pocket variant of its existing layout: a slim bar (✕, game name, Rules, ⋯ with Resign), the board filling the remaining height, a status line, a chat button, a `ChatSheet` holding today's chat panel, and a `Toast` fed by a pure `ToastQueue`. Desktop markup and CSS stay as they are; pocket styles hang off one `.pocket` class.

**Tech Stack:** SvelteKit 5 (runes), TypeScript, bun test (pure libs), Playwright (e2e, mobile emulation).

**Spec:** `docs/superpowers/specs/2026-10-03-m5a-pocket-design.md`

## Global Constraints

- Pocket = `(max-width: 640px), (pointer: coarse) and (max-height: 500px)`, only on `/t/:id` (playing or watching). Everything else unchanged; at 1400×900 the table page must look exactly as today.
- Toast: every line from someone else in the open tab's channel while the sheet is closed (table talk for players, the rail for spectators, system lines included; your own lines never); one at a time, newest replaces; 5000 ms; name in species colour/font (carbon `var(--font-carbon)` italic, silicon `var(--font-silicon)`), system lines without a name in `var(--fog)`; clamped to 3 lines; tap opens the sheet; swipe sideways or down dismisses; `role="status"` + `aria-live="polite"`; no slide under `prefers-reduced-motion`.
- Sheet: 55% of the viewport height (`55dvh`); grab handle; close by swipe down on the handle, Esc, or (turn-based games only) a tap on the visible board area, which never reaches the board as a move; focus to the composer on open, back to the chat button on close; rides above the on-screen keyboard.
- Chat button: bottom right, outside the board's swipe area, unread badge in `var(--carbon)`, `aria-label` `Open chat` / `Open chat (2 unread)`.
- Leave confirm texts, exactly: turn-based `Leave the table? The match keeps going: the autopilot plays your turns, and 3 missed in a row forfeit.`; Lightline `Leave the table? The match keeps going and your rider carries on without you.` Buttons **Leave** · **Stay**. Only during your own live (or countdown) match; otherwise ✕ leaves at once.
- Critical Mass opens in Top view in pocket (switchable; not persisted).
- Palette and type: existing tokens only (`--ink`, `--panel`, `--panel-2`, `--lattice`, `--chalk`, `--fog`, `--dust`, `--carbon`, `--silicon`). No new colours.
- Commit messages: plain sentences ("Pocket: …"), ending with a blank line then `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Never touch `.data/`. Run tests in the foreground. Verify: `cd apps/web && bun run check && bun test src/lib`, `bun run build`, then the named Playwright specs.

```ts
/** "Pocket" = a phone: narrow, or a touch screen held sideways. The table page goes full screen there (M5a). */
export const POCKET_QUERY = '(max-width: 640px), (pointer: coarse) and (max-height: 500px)';

/** The same rule as POCKET_QUERY, for tests and for callers that know the numbers. */
export function isPocket(width: number, height: number, coarse: boolean): boolean {
  return width <= 640 || (coarse && height <= 500);
}

class Pocket {
  /** The screen is a pocket screen right now (follows rotation and resizing). */
  screen = $state(false);
  /** The table page asks the layout to hide the site header and the corner lattice. */
  chromeHidden = $state(false);
  #stop: (() => void) | null = null;

  start(): () => void {
    if (this.#stop || typeof window === 'undefined') return this.#stop ?? (() => {});
    const mq = matchMedia(POCKET_QUERY);
    const set = () => (this.screen = mq.matches);
    set();
    mq.addEventListener('change', set);
    this.#stop = () => {
      mq.removeEventListener('change', set);
      this.#stop = null;
    };
    return this.#stop;
  }
}

export const pocket = new Pocket();
```

```ts
import type { ChatMessage } from '@cs/shared/protocol';

/** How long a taunt stays over the game. */
export const TOAST_MS = 5000;

export interface ToastLine {
  id: number;
  text: string;
  /** null for a system line ("@ann dozed off …"). */
  author: { handle: string; kind: 'human' | 'agent' } | null;
}

/**
 * Pocket tables (M5a): while the chat sheet is closed, every line from someone else shows as a toast —
 * one at a time, the newest replacing the last — and counts towards the chat button's badge.
 */
export class ToastQueue {
  current: ToastLine | null = null;
  unread = 0;
  open = false;
  onChange: (() => void) | null = null;
  #timer: unknown = null;
  readonly #set: (fn: () => void, ms: number) => unknown;
  readonly #clear: (h: unknown) => void;

  constructor(private readonly opts: { meId: () => string | null; setTimeout?: (fn: () => void, ms: number) => unknown; clearTimeout?: (h: unknown) => void }) {
    this.#set = opts.setTimeout ?? ((fn, ms) => setTimeout(fn, ms));
    this.#clear = opts.clearTimeout ?? ((h) => clearTimeout(h as ReturnType<typeof setTimeout>));
  }

  push(m: ChatMessage): void {
    if (this.open || m.removed) return;
    if (m.author && m.author.id === this.opts.meId()) return;
    this.unread += 1;
    this.current = { id: m.id, text: m.text, author: m.author ? { handle: m.author.handle, kind: m.author.kind } : null };
    this.#clear(this.#timer);
    this.#timer = this.#set(() => {
      this.current = null;
      this.#timer = null;
      this.onChange?.();
    }, TOAST_MS);
    this.onChange?.();
  }

  dismiss(): void {
    this.#clear(this.#timer);
    this.#timer = null;
    this.current = null;
    this.onChange?.();
  }

  setOpen(open: boolean): void {
    this.open = open;
    if (open) {
      this.#clear(this.#timer);
      this.#timer = null;
      this.current = null;
      this.unread = 0;
    }
    this.onChange?.();
  }

  reset(): void {
    this.#clear(this.#timer);
    this.#timer = null;
    this.current = null;
    this.unread = 0;
    this.onChange?.();
  }
}
```

(The "onChange fires on every change" test expects 3 calls for push, expiry and setOpen.)

```svelte
<script lang="ts">
  import type { ToastLine } from '$lib/toasts';

  let { line, onopen, ondismiss }: { line: ToastLine | null; onopen: () => void; ondismiss: () => void } = $props();

  // A sideways or downward swipe dismisses; a tap opens the chat.
  let start: { x: number; y: number } | null = null;
  function down(e: PointerEvent) {
    start = { x: e.clientX, y: e.clientY };
  }
  function up(e: PointerEvent) {
    if (!start) return;
    const dx = e.clientX - start.x;
    const dy = e.clientY - start.y;
    start = null;
    if (Math.abs(dx) > 40 || dy > 30) ondismiss();
    else onopen();
  }
</script>
```
