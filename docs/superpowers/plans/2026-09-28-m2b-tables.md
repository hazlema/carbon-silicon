# Milestone 2b "Tables" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn invites, "vs house", rematch, spectating and 3–4 player matches into one idea — the **table** — so a human picks a game, clicks the people they want in the lobby chat, and presses Start; agents do the same over HTTP; spectators watch and talk on the rail. Plus the M2a must-do: closing open sockets on session revoke, release and IP ban.

**Architecture:** A new in-memory core class `TableManager` (`apps/server/src/core/tables.ts`) owns tables and invites and calls the existing `GameManager.createMatch` when the host presses Start. Matches gain a `table_id`. Table chat moves to `table:<id>` (kept across rematches) with `rail:<id>` for spectators; `match:<id>` stays as an alias. Both doors share the core methods: new HTTP routes in `apps/server/src/http/tables.ts`, new inbox events, and WebSocket pushes (`tables`, `table`). Quick match becomes "a full 2-seat table that starts at once". The web gathers tables in the lobby (Play panel card, name menu, `/invite`) and moves the table page to `/t/:id`.

**Tech Stack:** Bun 1.3.13, TypeScript 6.0.3, Hono 4.13.9, Drizzle ORM 0.45.3 + drizzle-kit 0.31.11, @electric-sql/pglite 0.5.8, postgres 3.4.9, Svelte 5.57.1 + SvelteKit 2.70.3, Playwright 1.63.0. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-28-m2b-tables-design.md` (all of it), extending `docs/superpowers/specs/2026-09-26-robot-games-design.md` and `docs/superpowers/specs/2026-09-27-m2a-keys-and-bouncers-design.md`. Read the M2b spec before starting.

## Global Constraints

- All M1 and M2a global constraints still hold (`docs/superpowers/plans/2026-09-27-m2a-keys-and-bouncers.md`): Bun 1.3.x, TypeScript ES modules, `@cs/*` workspace packages consumed as source, exact pinned versions, time only from the injected `Clock` in server managers, `*.test.ts` for bun tests, `*.e2e.ts` for Playwright, error body `{ "error": { "code": "UPPER_SNAKE", "message": "human sentence" } }`.
- New error codes (exact): `AT_TABLE` (409), `TABLE_FULL` (409), `NOT_ENOUGH` (409), `NOT_AVAILABLE` (409), `HOUSE_FULL` (409), `ALREADY_INVITED` (409), `TABLE_BUSY` (409), `OUT` (409), `NO_TABLE` (404), `NOT_HOST` (403), `NOT_OPEN` (403), `INVITE_GONE` (410), `BAD_HANDLES` (400). Existing codes reused: `NOT_SEATED` (403), `IN_MATCH`, `NOT_READY`, `HOUSE_WAITS`, `NO_USER`, `SELF`, `SLOW_DOWN` (429), `NO_GAME`, `BAD_GAME`.
- A table's size is the game's `maxPlayers`; Start needs the game's `minPlayers` seated. Nobody picks a seat count.
- Invites last **60 s**. A decline blocks re-inviting that person for **2 min**. At most **10 invites per minute** per host. A forming table with no seat/invite change for **10 min** closes (`idle`). A finished table closes **30 min** after its match (`done`).
- Table ids start `t_`, invite ids `i_` (`newId`). Channels: `table:<tableId>`, `rail:<tableId>`; `match:<matchId>` is an alias.
- Exact copy (used by server and web):
  - Too early: `` `${gameName} needs at least ${min} players — invite ${n} more to start.` ``
  - Full: `` `The table is full — @${hostHandle}, start when you're ready.` ``
  - `` `@${handle} sat down.` `` · `` `@${handle} declined.` `` · `` `@${handle}'s invite expired — the seat is empty.` `` · `` `@${handle} left the table.` `` · `` `@${handle} wants a rematch.` `` · `` `@${handle} isn't around for a rematch.` ``
  - No house bot: `The house is full — try quick match.`
- The WebSocket "signed out" close code is **4001**.
- The corner dock (invite cards, compact gathering card) sits **bottom-left**; the Lattice tiles own bottom-right on `/` and `/t/`.

## Review Focus

1. **Two things happen to one table at once** — the host presses Start while a guest accepts, or a player accepts an invite to table B while seated at table A which they host. Expected: Start locks the table (`starting`), a late accept gets `409 TABLE_BUSY`, and moving tables disbands A with a notice. Pinned in Task 4 (starting lock + rollback, "accept moves you").
2. **An invitee who stops being available** — goes AFK, starts a quick match, gets suspended — while their invite card is still showing. Expected: the invite is withdrawn (`invite.cancelled`), the host's card updates, and a late Accept gets `410 INVITE_GONE`. Pinned in Task 4 (AFK) and Task 5 (match start, bench).
3. **A player who is out of a 3–4 player match** (resigned or eliminated) tries to play elsewhere while the match runs on. Expected: they can host, sit or quick-match (they're no longer "at" the table), and resigning again gets `409 OUT` without disturbing the match. Pinned in Task 2 (OUT) and Task 5 (atTable after resign).
4. **Old links and old agents** — `/play/m_…` bookmarks, agents posting to `match:<id>`, bots reading `chat.table` with a `table:` channel. Expected: `/play` redirects to the table, `match:` posts land in the table channel, bots keep talking at their table. Pinned in Task 3 (alias), Task 6 (HTTP alias), Task 8 (bots), Task 9 (redirect).
5. **A browser whose session is revoked elsewhere** still has the lobby open. Expected: its socket closes with 4001 and it falls back to the handle gate instead of reconnecting forever. Pinned in Task 7 (server) and Task 10 (client).

## Rulings made while planning

Each: what — why — cost if wrong.

- P1 — The spec's "keyboard players can reach every cell" and "reconnect after grace shows playing" fixes already shipped in M2a (`e2e/match.e2e.ts` keyboard test, `apps/server/src/ws/hub.test.ts`). No task re-does them; Task 2 only keeps those tests green — costs nothing.
- P2 — Unseating someone (left, removed, away) always sends them `table.closed` with the reason, so their card disappears — the spec only said so for disbanding — costs one extra event.
- P3 — A tableless live match (unit tests call `createMatch` without a table) keeps a postable `match:<id>` channel through `setMatchAccess` — cheaper than making every GameManager test build a table — costs a second access hook in CommunicationManager.
- P4 — A busy house bot declines silently unless it was one of the table's last players (rematch), because only seated and last players may post at a table — the spec's "in-character line" needs chat rights — costs: most busy declines are silent.
- P5 — The Rail tab's number is unread rail lines while you're on the Table tab (the header already shows "Watching: n") — costs nothing.
- P6 — `@mention` menus open only for people in Here now (the menu needs their identity, and only people present can be invited) — costs: a mention of an absent person is plain text.
- P7 — `/invite` never grows a table: size is the game's `maxPlayers`, so a name that doesn't fit gets the `TABLE_FULL` wording (the spec's §2 "grows the table if needed" predates the fixed-size decision) — costs nothing.

```ts
export interface TableOptions {
  inviteMs: number;
  idleMs: number;
  retainMs: number;
  declineCooldownMs: number;
  invitesPerMinute: number;
  /** Seat order for a new match; tests pass the identity function. */
  shuffle: <T>(items: T[]) => T[];
}

function shuffled<T>(items: T[]): T[] {
  const out = [...items];
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [out[i], out[j]] = [out[j], out[i]];
  }
  return out;
}

const DEFAULTS: TableOptions = {
  inviteMs: 60_000,
  idleMs: 10 * 60_000,
  retainMs: 30 * 60_000,
  declineCooldownMs: 2 * 60_000,
  invitesPerMinute: 10,
  shuffle: shuffled,
};

interface Invite {
  id: string;
  tableId: string;
  to: IdentityPublic;
  expiresAt: number;

}

interface Table {
  id: string;
  gameId: string;
  host: IdentityPublic;
  status: TableStatus;
  open: boolean;
  seated: IdentityPublic[];
  invites: Invite[];
  lastPlayers: IdentityPublic[];
  matchId: string | null;
  watching: number;
  /** The idle timer while forming, the retention timer once finished. */
  timer: unknown;
  /** System lines go out one after another, in order. */

const wire = (i: Invite): TableInvite => ({ id: i.id, to: i.to, expiresAt: new Date(i.expiresAt).toISOString() });
const bare = (handle: string) => handle.trim().replace(/^@/, '');
const unavailable = (who: IdentityPublic) => conflict('NOT_AVAILABLE', `@${who.handle} can't take an invite right now.`);
const fullText = (t: { host: IdentityPublic }) => `The table is full — @${t.host.handle}, start when you're ready.`;

/** 1–3 handles, as an array of strings (a single string is accepted too). */
function handlesOf(raw: unknown): string[] {
  const list = typeof raw === 'string' ? [raw] : raw;
  if (!Array.isArray(list) || list.length === 0 || list.length > 3 || !list.every((h) => typeof h === 'string' && bare(h))) {
    throw badRequest('BAD_HANDLES', 'Send {"handles": ["someone"]}: one to three names.');
  }
  return list.map((h: string) => bare(h));
}

/**
 * Tables (spec M2b §2): a host, a game, and up to the game's maxPlayers seats, filled by invites
 * or, at an open table, by anyone. The host presses Start; the match runs at the table; a rematch
 * gathers the same table again. Everything lives in memory, like running matches.
 */
export class TableManager {
  private tables = new Map<string, Table>();
  /** identityId → the table they sit at (forming, starting or playing). */
  private seatOf = new Map<string, string>();
  private invites = new Map<string, Invite>();
  /** `${hostId}:${targetId}` → when the host may invite them again. */
  private declined = new Map<string, number>();
  private limiter: RateLimiter;
  private leaveQueue: (identityId: string) => void = () => {};
  private opts: TableOptions;

  constructor(
    private deps: TableDeps,
    opts: Partial<TableOptions> = {},
  ) {
    this.opts = { ...DEFAULTS, ...opts };
    this.limiter = new RateLimiter(deps.clock, this.opts.invitesPerMinute, this.opts.invitesPerMinute / 60_000);
    deps.comms.setTableAccess((tableId) => {
      const t = this.tables.get(tableId);
      return t ? { posters: this.posters(t) } : null;
    });
    deps.bus.on('match.finished', ({ matchId, tableId }) => {
      if (tableId) this.onFinished(tableId, matchId);
    });
    deps.bus.on('presence.changed', (p) => {
      if (p.status !== 'ready') this.onUnavailable(p.identity.id);
    });
  }

  /** Sitting down takes you out of the quick-match queue (InviteManager installs this). */
  setQueueLeaver(fn: (identityId: string) => void): void {
    this.leaveQueue = fn;
  }

  // ── reads ──

  get(tableId: string, viewerId: string | null): TableInfo {
    return this.info(this.require(tableId), viewerId);
  }

  /** The lobby's list: open tables still gathering, and tables playing now. Never shows invites. */
  list(): TableInfo[] {
    return [...this.tables.values()]
      .filter((t) => (t.status === 'forming' && t.open) || t.status === 'playing')
      .map((t) => this.info(t, null));
  }

  tableFor(identityId: string): TableInfo | null {
    const id = this.atTable(identityId);
    return id ? this.info(this.tables.get(id)!, identityId) : null;
  }

  offersFor(identityId: string): InviteOffer[] {
    const out: InviteOffer[] = [];
    for (const inv of this.invites.values()) {
      const t = this.tables.get(inv.tableId);
      if (t && inv.to.id === identityId) out.push({ invite: wire(inv), from: t.host, table: this.info(t, identityId) });
    }
    return out;
  }

  /** The table someone is at. A player already out of a running match is no longer "at" it. */
  atTable(identityId: string): string | null {
    const id = this.seatOf.get(identityId);
    const t = id ? this.tables.get(id) : undefined;
    if (!t) return null;
    if (t.status === 'playing' && this.deps.games.activeMatchOf(identityId) !== t.matchId) return null;
    return t.id;
  }

  /** At a table, or holding an invite to one (quick match's house fallback skips them). */
  isBusy(identityId: string): boolean {
    if (this.atTable(identityId)) return true;
    for (const inv of this.invites.values()) if (inv.to.id === identityId) return true;
    return false;
  }

  // ── gathering ──

  async host(identity: IdentityPublic, gameId: unknown, opts: { invite?: unknown; open?: unknown } = {}): Promise<TableInfo> {
    if (typeof gameId !== 'string') throw badRequest('BAD_GAME', 'Send {"gameId": "critical-mass"}.');
    const meta = this.deps.games.module(gameId).meta;
    if (identity.isHouse) throw forbidden('HOUSE_WAITS', 'House bots join tables; they never host.');
    this.assertFree(identity);
    if (this.atTable(identity.id)) throw conflict('AT_TABLE', "You're already at a table. Leave it first.");
    if (opts.open !== undefined && typeof opts.open !== 'boolean') throw badRequest('BAD_FIELD', 'open is true or false.');
    const t: Table = {
      id: newId('t'),
      gameId,
      host: identity,
      status: 'forming',
      open: opts.open === true,
      seated: [],
      invites: [],
      lastPlayers: [],
      matchId: null,
      watching: 0,
      timer: null,
      lines: Promise.resolve(),
    };
    this.tables.set(t.id, t);
    this.seat(t, identity);
    this.say(t, `@${identity.handle} opened a table for ${meta.name}.`);
    this.touch(t);
    if (opts.invite === undefined) {
      this.changed(t);
    } else {
      try {
        await this.invite(identity, t.id, opts.invite);
      } catch (e) {
        this.close(t, 'cancelled');
        throw e;
      }
    }
    return this.info(t, identity.id);
  }

  async invite(identity: IdentityPublic, tableId: string, rawHandles: unknown): Promise<TableInfo> {
    const t = this.asHost(identity, tableId);
    this.assertForming(t);
    const handles = handlesOf(rawHandles);
    const targets: IdentityPublic[] = [];
    for (const handle of handles) {
      const who = await this.deps.identities.getByHandle(handle);
      if (!who || who.released) throw notFound('NO_USER', `There is no @${handle}.`);
      if (who.id === identity.id) throw badRequest('SELF', "You're already at your own table.");
      if (!targets.some((x) => x.id === who.id)) targets.push(who);
    }
    for (const who of targets) {
      if (await this.deps.relations.blocks(who.id, identity.id)) throw unavailable(who);
    }
    // From here on nothing awaits, so the checks and the writes see the same table.
    this.assertForming(t);
    const now = this.deps.clock.now();
    for (const who of targets) {
      if (t.seated.some((x) => x.id === who.id) || t.invites.some((x) => x.to.id === who.id)) {
        throw conflict('ALREADY_INVITED', `@${who.handle} is already at this table.`);
      }
      if (!this.available(who)) throw unavailable(who);
      if ((this.declined.get(`${identity.id}:${who.id}`) ?? 0) > now) {
        throw tooMany('SLOW_DOWN', `@${who.handle} said no a moment ago. Give it a couple of minutes.`);
      }
    }
    if (this.taken(t) + targets.length > this.size(t)) throw conflict('TABLE_FULL', fullText(t));
    let spent = 0;
    for (; spent < targets.length; spent++) {
      if (!this.limiter.take(identity.id)) {
        for (let i = 0; i < spent; i++) this.limiter.refund(identity.id);
        throw tooMany('SLOW_DOWN', 'That is a lot of invites. Give it a minute.');
      }
    }
    for (const who of targets) this.addInvite(t, identity, who);
    this.touch(t);
    this.changed(t);
    return this.info(t, identity.id);
  }

  accept(identity: IdentityPublic, inviteId: string): TableInfo {
    const inv = this.invites.get(inviteId);
    const t = inv ? this.tables.get(inv.tableId) : undefined;
    if (!inv || !t || inv.to.id !== identity.id) throw gone('INVITE_GONE', 'That invite has expired, or the table is gone.');
    this.assertForming(t);
    this.assertFree(identity);
    this.forgetInvite(inv);
    this.seat(t, identity);
    this.deps.comms.deliver(t.host.id, { type: 'invite.answered', inviteId: inv.id, tableId: t.id, who: identity, answer: 'accepted' });
    this.sat(t, identity);
    return this.info(t, identity.id);
  }

  decline(identity: IdentityPublic, inviteId: string): void {
    const inv = this.invites.get(inviteId);
    if (!inv || inv.to.id !== identity.id) throw gone('INVITE_GONE', 'That invite has expired, or the table is gone.');
    this.forgetInvite(inv);
    const t = this.tables.get(inv.tableId);
    if (!t) return;
    this.declined.set(`${t.host.id}:${identity.id}`, this.deps.clock.now() + this.opts.declineCooldownMs);
    this.deps.comms.deliver(t.host.id, { type: 'invite.answered', inviteId: inv.id, tableId: t.id, who: identity, answer: 'declined' });
    this.say(t, `@${identity.handle} declined.`);
    this.changed(t);
  }

  async sit(identity: IdentityPublic, tableId: string): Promise<TableInfo> {
    const t = this.require(tableId);
    this.assertForming(t);
    if (t.seated.some((x) => x.id === identity.id)) return this.info(t, identity.id);
    const mine = t.invites.find((i) => i.to.id === identity.id);
    if (mine) return this.accept(identity, mine.id);
    if (!t.open) throw forbidden('NOT_OPEN', 'This table is invite-only.');
    this.assertFree(identity);
    if (await this.deps.relations.blocks(t.host.id, identity.id)) throw forbidden('NOT_OPEN', 'This table is invite-only.');
    this.assertForming(t);
    if (this.taken(t) >= this.size(t)) throw conflict('TABLE_FULL', fullText(t));
    this.seat(t, identity);
    this.sat(t, identity);
    return this.info(t, identity.id);
  }

  leave(identity: IdentityPublic, tableId: string): void {
    const t = this.require(tableId);
    if (!t.seated.some((x) => x.id === identity.id)) throw forbidden('NOT_SEATED', "You're not at this table.");
    if (t.status !== 'forming') throw conflict('TABLE_BUSY', 'The match is on. Resign to leave it.');
    this.unseat(t, identity.id, 'left');
  }

  remove(identity: IdentityPublic, tableId: string, rawHandle: unknown): TableInfo {
    const t = this.asHost(identity, tableId);
    this.assertForming(t);
    const handle = typeof rawHandle === 'string' ? bare(rawHandle).toLowerCase() : '';
    const inv = t.invites.find((i) => i.to.handle.toLowerCase() === handle);
    if (inv) {
      this.dropInvite(inv, 'withdrawn');
      this.touch(t);
      this.changed(t);
      return this.info(t, identity.id);
    }
    const who = t.seated.find((x) => x.handle.toLowerCase() === handle && x.id !== t.host.id);
    if (!who) throw notFound('NOT_SEATED', `@${handle} isn't at this table.`);
    this.unseat(t, who.id, 'removed');
    return this.info(t, identity.id);
  }

  setOpen(identity: IdentityPublic, tableId: string, open: unknown): TableInfo {
    const t = this.asHost(identity, tableId);
    this.assertForming(t);
    if (typeof open !== 'boolean') throw badRequest('BAD_FIELD', 'open is true or false.');
    t.open = open;
    this.touch(t);
    this.changed(t);
    return this.info(t, identity.id);
  }

  async start(identity: IdentityPublic, tableId: string): Promise<MatchSummary> {
    const t = this.asHost(identity, tableId);
    this.assertForming(t);
    const meta = this.deps.games.module(t.gameId).meta;
    if (t.seated.length < meta.minPlayers) {
      const short = meta.minPlayers - t.seated.length;
      throw conflict('NOT_ENOUGH', `${meta.name} needs at least ${meta.minPlayers} players — invite ${short} more to start.`);
    }
    return this.launch(t);
  }

  disband(identity: IdentityPublic, tableId: string): void {
    const t = this.asHost(identity, tableId);
    if (t.status === 'starting' || t.status === 'playing') throw conflict('TABLE_BUSY', 'The match is on. Resign to leave it.');
    this.close(t, 'disbanded');
  }

  // ── inner workings ──

  private require(tableId: string): Table {
    const t = this.tables.get(tableId);
    if (!t) throw notFound('NO_TABLE', 'There is no such table. It may have been cleared.');
    return t;
  }

  private asHost(identity: IdentityPublic, tableId: string): Table {
    const t = this.require(tableId);
    if (t.host.id !== identity.id) throw forbidden('NOT_HOST', 'Only the host can do that.');
    return t;
  }

  private assertForming(t: Table): void {
    if (t.status !== 'forming' || !this.tables.has(t.id)) {
      throw conflict('TABLE_BUSY', 'That table is not gathering players right now.');
    }
  }

  /** The caller may take a seat: allowed to play, not in a match, and ready. */
  private assertFree(identity: IdentityPublic): void {
    this.deps.guard.assert(identity, 'play');
    if (this.deps.games.activeMatchOf(identity.id)) throw conflict('IN_MATCH', 'Finish your current match first.');
    if (!this.deps.presence.isReady(identity.id)) throw conflict('NOT_READY', 'Set your status to ready first.');
  }

  /** Could this person take an invite right now? (Blocks are checked separately; they need the database.) */
  private available(who: IdentityPublic): boolean {
    if (!this.deps.presence.isReady(who.id) || this.deps.games.activeMatchOf(who.id)) return false;
    try {
      this.deps.guard.assert(who, 'play');
      return true;
    } catch (e) {
      if (e instanceof AppError) return false;
      throw e;
    }
  }

  private size(t: Table): number {
    return this.deps.games.module(t.gameId).meta.maxPlayers;
  }

  private taken(t: Table): number {
    return t.seated.length + t.invites.length;
  }

  private posters(t: Table): string[] {
    return [...new Set([...t.seated, ...t.lastPlayers].map((p) => p.id))];
  }

  private info(t: Table, viewerId: string | null): TableInfo {
    const meta = this.deps.games.module(t.gameId).meta;
    const insider = viewerId !== null && (t.seated.some((p) => p.id === viewerId) || t.invites.some((i) => i.to.id === viewerId));
    return {
      id: t.id,
      gameId: t.gameId,
      host: t.host,
      status: t.status,
      open: t.open,
      size: meta.maxPlayers,
      minPlayers: meta.minPlayers,
      seated: [...t.seated],
      invites: insider ? t.invites.map(wire) : [],
      lastPlayers: [...t.lastPlayers],
      matchId: t.matchId,
      watching: t.watching,
    };
  }

  /** Everyone at the table (seated, invited, and after a match its players) hears about every change. */
  private changed(t: Table): void {
    const ids = new Set([...t.seated.map((p) => p.id), ...t.invites.map((i) => i.to.id)]);
    if (t.status === 'finished') for (const p of t.lastPlayers) ids.add(p.id);
    for (const id of ids) this.deps.comms.deliver(id, { type: 'table.updated', table: this.info(t, id) });
    this.deps.bus.emit('table.changed', { tableId: t.id });
  }

  private say(t: Table, text: string): void {
    t.lines = t.lines
      .then(() => this.deps.comms.postSystem(tableChannel(t.id), text))
      .catch((e) => console.error('[tables] system line failed', e));
  }

  /** (Re)arms the forgotten-table timer; every seat or invite change calls it while forming. */
  private touch(t: Table): void {
    this.deps.clock.clearTimeout(t.timer);
    t.timer = this.deps.clock.setTimeout(() => this.close(t, 'idle'), this.opts.idleMs);
  }

  private seat(t: Table, identity: IdentityPublic): void {
    const other = this.seatOf.get(identity.id);
    if (other && other !== t.id) {
      const o = this.tables.get(other);
      if (o?.status === 'forming') this.unseat(o, identity.id, 'left');
      else this.seatOf.delete(identity.id);
    }
    this.leaveQueue(identity.id);
    t.seated.push(identity);
    this.seatOf.set(identity.id, t.id);
  }

  private sat(t: Table, who: IdentityPublic): void {
    this.say(t, `@${who.handle} sat down.`);
    if (t.seated.length === this.size(t)) this.say(t, fullText(t));
    this.touch(t);
    this.changed(t);
  }

  /** Someone leaves a forming table (the host leaving disbands it). They're told why. */
  private unseat(t: Table, identityId: string, reason: 'left' | 'removed' | 'away'): void {
    if (t.host.id === identityId) {
      this.close(t, 'host-left');
      return;
    }
    const who = t.seated.find((p) => p.id === identityId);
    if (!who) return;
    t.seated = t.seated.filter((p) => p.id !== identityId);
    if (this.seatOf.get(identityId) === t.id) this.seatOf.delete(identityId);
    this.deps.comms.deliver(identityId, { type: 'table.closed', tableId: t.id, reason });
    this.say(t, `@${who.handle} left the table.`);
    this.touch(t);
    this.changed(t);
  }

  private addInvite(t: Table, from: IdentityPublic, to: IdentityPublic): void {
    const inv: Invite = { id: newId('i'), tableId: t.id, to, expiresAt: this.deps.clock.now() + this.opts.inviteMs, timer: null };
    inv.timer = this.deps.clock.setTimeout(() => this.expire(inv.id), this.opts.inviteMs);
    t.invites.push(inv);
    this.invites.set(inv.id, inv);
    this.deps.comms.deliver(to.id, { type: 'invite.received', invite: wire(inv), from, table: this.info(t, to.id) });
  }

  /** Takes an invite off its table without telling anyone. */
  private forgetInvite(inv: Invite): void {
    this.deps.clock.clearTimeout(inv.timer);
    this.invites.delete(inv.id);
    const t = this.tables.get(inv.tableId);
    if (t) t.invites = t.invites.filter((i) => i.id !== inv.id);
  }

  /** Takes an invite away and tells the invitee why. */
  private dropInvite(inv: Invite, reason: string): void {
    this.forgetInvite(inv);
    this.deps.comms.deliver(inv.to.id, { type: 'invite.cancelled', inviteId: inv.id, tableId: inv.tableId, reason });
  }

  private expire(inviteId: string): void {
    const inv = this.invites.get(inviteId);
    if (!inv) return;
    this.dropInvite(inv, 'expired');
    const t = this.tables.get(inv.tableId);
    if (!t) return;
    this.deps.comms.deliver(t.host.id, { type: 'invite.answered', inviteId: inv.id, tableId: t.id, who: inv.to, answer: 'expired' });
    this.say(t, `@${inv.to.handle}'s invite expired — the seat is empty.`);
    this.changed(t);
  }

  private async launch(t: Table): Promise<MatchSummary> {
    t.status = 'starting';
    this.deps.clock.clearTimeout(t.timer);
    t.timer = null;
    for (const inv of [...t.invites]) this.dropInvite(inv, 'started');
    const players = this.opts.shuffle(t.seated);
    try {
      const match = await this.deps.games.createMatch(t.gameId, players, { tableId: t.id });
      t.status = 'playing';
      t.matchId = match.id;
      t.lastPlayers = players;
      this.changed(t);
      return match;
    } catch (e) {
      t.status = 'forming';
      this.touch(t);
      this.changed(t);
      throw e;
    }
  }

  private onFinished(tableId: string, matchId: string): void {
    const t = this.tables.get(tableId);
    if (!t || t.matchId !== matchId) return;
    t.status = 'finished';
    for (const p of t.seated) if (this.seatOf.get(p.id) === t.id) this.seatOf.delete(p.id);
    t.seated = [];
    this.deps.clock.clearTimeout(t.timer);
    t.timer = this.deps.clock.setTimeout(() => this.close(t, 'done'), this.opts.retainMs);
    this.changed(t);
  }

  /** Not ready any more (AFK, playing, offline): invites to them go, and they lose a forming seat. */
  private onUnavailable(identityId: string): void {
    for (const inv of [...this.invites.values()]) {
      if (inv.to.id !== identityId) continue;
      this.dropInvite(inv, 'unavailable');
      const t = this.tables.get(inv.tableId);
      if (t) this.changed(t);
    }
    const id = this.seatOf.get(identityId);
    const t = id ? this.tables.get(id) : undefined;
    if (t?.status === 'forming') this.unseat(t, identityId, 'away');
  }

  private close(t: Table, reason: string): void {
    if (!this.tables.has(t.id)) return;
    this.deps.clock.clearTimeout(t.timer);
    for (const inv of [...t.invites]) this.dropInvite(inv, reason);
    for (const p of t.seated) {
      if (this.seatOf.get(p.id) === t.id) this.seatOf.delete(p.id);
      this.deps.comms.deliver(p.id, { type: 'table.closed', tableId: t.id, reason });
    }
    t.seated = [];
    this.tables.delete(t.id);
    this.deps.bus.emit('table.changed', { tableId: t.id });
  }
}
```

```ts
   * After a match, any of its players may call a rematch: the table gathers again with them as
   * host and the other players invited. Pressing Rematch once it's gathering sits you down.
   */
  async rematch(identity: IdentityPublic, tableId: string): Promise<TableInfo> {
    const t = this.require(tableId);
    if (!t.lastPlayers.some((p) => p.id === identity.id)) {
      throw forbidden('NOT_SEATED', "Only the last match's players can call a rematch.");
    }
    if (t.status === 'forming') {
      if (t.seated.some((p) => p.id === identity.id)) return this.info(t, identity.id);
      const mine = t.invites.find((i) => i.to.id === identity.id);
      if (mine) return this.accept(identity, mine.id);

      if (this.taken(t) >= this.size(t)) throw conflict('TABLE_FULL', fullText(t));
      this.seat(t, identity);
      this.sat(t, identity);
      return this.info(t, identity.id);
    }
    if (t.status !== 'finished') throw conflict('TABLE_BUSY', 'The match is still on.');
    this.assertFree(identity);
    if (this.atTable(identity.id)) throw conflict('AT_TABLE', "You're already at a table. Leave it first.");

    for (const p of t.lastPlayers) {
      if (p.id !== identity.id && (await this.deps.relations.blocks(p.id, identity.id))) blocked.add(p.id);
    }
    if (t.status !== 'finished' || !this.tables.has(t.id)) throw conflict('TABLE_BUSY', 'Someone else just called it.');
    this.deps.clock.clearTimeout(t.timer);
    t.status = 'forming';
    t.host = identity;
    t.seated = [];
    this.seat(t, identity);
    this.say(t, `@${identity.handle} wants a rematch.`);
    for (const p of t.lastPlayers) {
      if (p.id === identity.id) continue;
      if (blocked.has(p.id) || !this.available(p)) {
        this.say(t, `@${p.handle} isn't around for a rematch.`);
        continue;
      }
      this.addInvite(t, identity, p);
    }
    this.touch(t);
    this.changed(t);
    return this.info(t, identity.id);
  }

  /** Host a table and invite a ready house bot (the named one, if given). */
  async vsHouse(identity: IdentityPublic, gameId: unknown, bot?: unknown): Promise<TableInfo> {
    if (typeof gameId !== 'string') throw badRequest('BAD_GAME', 'Send {"gameId": "critical-mass"}.');
    this.deps.games.module(gameId);
    const want = typeof bot === 'string' && bare(bot) ? bare(bot).toLowerCase() : null;
    const pick = this.deps.presence
      .list()
      .find(

          p.identity.isHouse &&
          p.identity.id !== identity.id &&
          (!want || p.identity.handle.toLowerCase() === want) &&
          !this.isBusy(p.identity.id) &&
          this.available(p.identity),
      );
    if (!pick) throw conflict('HOUSE_FULL', 'The house is full — try quick match.');
    return this.host(identity, gameId, { invite: [pick.identity.handle] });
  }

  /** Quick match: a pair who were matched to play sit at a new table that starts at once. */
  async startNow(gameId: string, players: IdentityPublic[]): Promise<MatchSummary> {
    const t: Table = {
      id: newId('t'),
      gameId,
      host: players[0],
      status: 'forming',
      open: false,
      seated: [],
      invites: [],
      lastPlayers: [],
      matchId: null,
      watching: 0,
      timer: null,
      lines: Promise.resolve(),
    };
    this.tables.set(t.id, t);
    for (const p of players) this.seat(t, p);
    try {
      return await this.launch(t);
    } catch (e) {
      this.close(t, 'cancelled');
      throw e;
    }
  }

  /** A suspension or a release: out of any forming seat, and every invite to them withdrawn. */
  bench(identityId: string): void {
    this.onUnavailable(identityId);
  }

  setWatching(tableId: string, n: number): void {
    const t = this.tables.get(tableId);
    if (!t || t.watching === n) return;
    t.watching = n;
    this.deps.bus.emit('table.changed', { tableId });
  }
```

````markdown
A table looks like this:

```json
{"id":"t_…","gameId":"critical-mass","host":{…},"status":"forming","open":false,
 "size":4,"minPlayers":2,"seated":[{…}],"invites":[{"id":"i_…","to":{…},"expiresAt":"…"}],
 "lastPlayers":[],"matchId":null,"watching":0}
```

`status` is `forming` (gathering), `starting`, `playing` or `finished`. `invites` is empty unless
you are seated or invited. Invites last 60 seconds; someone who declines can't be invited by the
same host again for 2 minutes; a host may send 10 invites a minute. A table gathering for 10
minutes with no change closes; a finished table closes 30 minutes after its match.

Inbox events: `invite.received {invite, from, table}`, `invite.answered {inviteId, tableId, who, answer}`
(to the host: `accepted`, `declined` or `expired`), `invite.cancelled {inviteId, tableId, reason}`,
`table.updated {table}` (to everyone seated or invited, on every change) and
`table.closed {tableId, reason}`. `match.started` carries `match.tableId`.

Chat: the players talk at `table:<id>` for the table's whole life (rematches included); spectators
talk on the rail, `rail:<id>`. `match:<matchId>` still works and means the match's table channel.

### GET /api/tables
Open tables still gathering, and tables playing now: `{tables: [table]}`. No auth.

### GET /api/tables/:id
`{table}`. `404 NO_TABLE` once it's cleared.

### POST /api/tables
`{gameId, invite?: ["handle", …], open?: false}` → `201 {table}`, with you seated as host.
`409 AT_TABLE` if you're at another table, `409 IN_MATCH`, `409 NOT_READY`, `403 HOUSE_WAITS` for house bots.

### PATCH /api/tables/:id
Host only: `{open: true|false}` → `{table}`.

### DELETE /api/tables/:id
Host only: disband → `204`. `409 TABLE_BUSY` while a match is on.

### POST /api/tables/:id/invite
Host only: `{handles: ["a", "b"]}` (one to three) → `{table}`. `409 NOT_AVAILABLE` when someone is
AFK, playing, offline or not taking invites from you; `409 TABLE_FULL`; `409 ALREADY_INVITED`;
`429 SLOW_DOWN`.

### POST /api/tables/:id/sit
Take an empty seat at an open table → `{table}`. `403 NOT_OPEN`, `409 TABLE_FULL`, `409 TABLE_BUSY`.

### POST /api/tables/:id/leave
Leave a table that's gathering → `204`. The host leaving disbands it.

### POST /api/tables/:id/remove
Host only: `{handle}` unseats someone or withdraws their invite → `{table}`.

### POST /api/tables/:id/start
Host only → `{match}`. `409 NOT_ENOUGH` below the game's minimum (the message says how many more).
Pending invites are withdrawn and seat order is shuffled.

### POST /api/tables/:id/rematch
Any player from the last match → `{table}`: the table gathers again with you as host and the other
players invited. If someone already called it, this sits you down.

### POST /api/invites
Shorthand for hosting and inviting one person: `{to: "handle", gameId}` → `201 {table}`.

### POST /api/invites/:id/accept
→ `{table}`; you're seated. Accepting while seated at another gathering table moves you.
`410 INVITE_GONE` if it expired or the table is gone.

### POST /api/invites/:id/decline
→ `204`.

### POST /api/vs-house

`409 HOUSE_FULL` when every house bot is busy.
````

```ts
import type { ServerWebSocket } from 'bun';
import type { IdentityPublic, WsClientMsg, WsServerMsg } from '@cs/shared/protocol';
import type { Core } from '../core/core';

export interface WsData {
  identity: IdentityPublic;
  /** The session this socket signed in with; revoking it closes the socket. */
  sessionId: string | null;
  /** The client's address; banning it closes the socket. */
  ip: string | null;
  channels: Set<string>;
  matches: Set<string>;
  tables: Set<string>;
}
type Socket = ServerWebSocket<WsData>;

/** Close code for "your session ended": the page re-reads who it is instead of reconnecting blindly. */
export const SIGNED_OUT = 4001;

const send = (ws: Socket, msg: WsServerMsg) => {
  ws.send(JSON.stringify(msg));
};

/** The human door: pushes presence, subscribed chat, inbox events, watched matches and tables. */
export class WsHub {
  private all = new Set<Socket>();
  private byIdentity = new Map<string, Set<Socket>>();
  private offs: (() => void)[] = [];

  constructor(private core: Core) {
    this.offs.push(
      core.bus.on('presence.changed', (presence) => {
        for (const ws of this.all) send(ws, { type: 'presence', presence });
      }),
      core.bus.on('chat.message', (message) => {
        for (const ws of this.all) if (ws.data.channels.has(message.channel)) send(ws, { type: 'chat', message });
      }),
      core.bus.on('chat.removed', (removed) => {
        for (const ws of this.all) if (ws.data.channels.has(removed.channel)) send(ws, { type: 'chat.removed', ...removed });
      }),
      core.bus.on('inbox', ({ identityId, event }) => {
        for (const ws of this.byIdentity.get(identityId) ?? []) send(ws, { type: 'inbox', event });
      }),
      core.bus.on('match.updated', ({ matchId }) => {
        for (const ws of this.all) if (ws.data.matches.has(matchId)) this.pushMatch(ws, matchId);
      }),
      core.bus.on('table.changed', ({ tableId }) => this.tableChanged(tableId)),
      core.bus.on('sessions.ended', ({ sessionIds }) => {
        const ended = new Set(sessionIds);
        for (const ws of [...this.all]) if (ws.data.sessionId && ended.has(ws.data.sessionId)) ws.close(SIGNED_OUT, 'signed out');
      }),
      core.bus.on('ip.banned', ({ ip }) => {
        for (const ws of [...this.all]) if (ws.data.ip === ip) ws.close(SIGNED_OUT, 'signed out');
      }),
    );
  }

  private pushMatch(ws: Socket, matchId: string): void {
    try {
      send(ws, { type: 'match', envelope: this.core.games.envelope(matchId, ws.data.identity.id) });
    } catch {
      ws.data.matches.delete(matchId);
    }
  }

  private pushTable(ws: Socket, tableId: string): void {
    try {
      send(ws, { type: 'table', table: this.core.tables.get(tableId, ws.data.identity.id) });
    } catch {
      ws.data.tables.delete(tableId);
      send(ws, { type: 'table.gone', tableId });
    }
  }

  private tableChanged(tableId: string): void {
    const tables = this.core.tables.list();
    for (const ws of this.all) {
      send(ws, { type: 'tables', tables });
      if (ws.data.tables.has(tableId)) this.pushTable(ws, tableId);
    }
    this.recount(tableId);
  }

  /** Spectators: distinct people with the table page open who aren't its players. */
  private recount(tableId: string): void {
    let players: Set<string>;
    try {
      const t = this.core.tables.get(tableId, null);
      players = new Set([...t.seated, ...t.lastPlayers].map((p) => p.id));
    } catch {
      return;
    }
    const watchers = new Set<string>();
    for (const ws of this.all) {
      if (ws.data.tables.has(tableId) && !players.has(ws.data.identity.id)) watchers.add(ws.data.identity.id);
    }
    this.core.tables.setWatching(tableId, watchers.size);
  }

  readonly handlers = {
    open: (ws: Socket) => {
      this.all.add(ws);
      const id = ws.data.identity.id;
      const set = this.byIdentity.get(id) ?? new Set<Socket>();
      set.add(ws);
      this.byIdentity.set(id, set);
      this.core.presence.humanConnected(ws.data.identity);
      // Back after the grace period: presence forgot the match, the game manager didn't.
      if (this.core.games.activeMatchOf(id)) this.core.presence.setPlaying(id, true);
      send(ws, { type: 'hello', identity: ws.data.identity, presence: this.core.presence.list() });
      send(ws, { type: 'tables', tables: this.core.tables.list() });
    },
    message: (ws: Socket, raw: string | Buffer) => {
      this.core.presence.humanActivity(ws.data.identity.id);
      let msg: WsClientMsg;
      try {
        msg = JSON.parse(String(raw));
      } catch {
        return;
      }
      switch (msg?.type) {
        case 'subscribe':
          if (typeof msg.channel === 'string' && this.core.comms.channelKind(msg.channel)) ws.data.channels.add(msg.channel);
          break;
        case 'unsubscribe':
          ws.data.channels.delete(msg.channel);
          break;
        case 'watch':
          if (typeof msg.matchId === 'string') {
            ws.data.matches.add(msg.matchId);
            this.pushMatch(ws, msg.matchId);
          }
          break;
        case 'unwatch':
          ws.data.matches.delete(msg.matchId);
          break;
        case 'watchTable':
          if (typeof msg.tableId === 'string') {
            ws.data.tables.add(msg.tableId);
            this.pushTable(ws, msg.tableId);
            this.recount(msg.tableId);
          }
          break;
        case 'unwatchTable':
          if (ws.data.tables.delete(msg.tableId)) this.recount(msg.tableId);
          break;
        case 'ping':
          send(ws, { type: 'pong' });
          break;
      }
    },
    close: (ws: Socket) => {
      this.all.delete(ws);
      const id = ws.data.identity.id;
      const set = this.byIdentity.get(id);
      set?.delete(ws);
      if (set && set.size === 0) this.byIdentity.delete(id);
      this.core.presence.humanDisconnected(id);
      for (const tableId of ws.data.tables) this.recount(tableId);
    },
  };

  stop(): void {
    for (const off of this.offs) off();
  }
}
```

```ts
import type { GameInfo, IdentityPublic, Status, TableInfo } from '@cs/shared/protocol';

/** The line the gathering card shows under the seats (same wording as the server's system lines). */
export function gatherNote(t: TableInfo, gameName: string): string {
  if (t.seated.length >= t.size) return `The table is full — @${t.host.handle}, start when you're ready.`;
  const short = t.minPlayers - t.seated.length;
  if (short > 0) return `${gameName} needs at least ${t.minPlayers} players — invite ${short} more to start.`;
  return t.invites.length > 0 ? 'Start now, or wait for the rest.' : 'Click a name to invite more, or start.';
}

export const secondsLeft = (iso: string, now: number): number => Math.max(0, Math.ceil((Date.parse(iso) - now) / 1000));

/** `/invite a, @b c` → ['a', 'b', 'c']; null when the text isn't an /invite command. */
export function parseInviteCommand(text: string): string[] | null {
  const m = /^\/invite(?:\s+(.*))?$/i.exec(text.trim());
  if (!m) return null;
  return (m[1] ?? '')
    .split(/[\s,]+/)
    .map((w) => w.replace(/^@/, ''))
    .filter(Boolean);
}

/** A trailing word that names a game picks it: `/invite bob critical-mass`. */
export function splitGame(words: string[], catalog: GameInfo[]): { handles: string[]; game: GameInfo | null } {
  const last = words.at(-1)?.toLowerCase();
  const game = catalog.find((g) => g.id === last);
  return game && words.length > 1 ? { handles: words.slice(0, -1), game } : { handles: words, game: null };
}

/** The named game, else the game whose channel you're in, else the only game there is. */
export function gameFor(explicit: GameInfo | null, channel: string, catalog: GameInfo[]): GameInfo | null {
  return explicit ?? catalog.find((g) => g.id === channel) ?? (catalog.length === 1 ? catalog[0] : null);
}

export type InviteChoice = { kind: 'invite'; label: string; disabled: string | null } | { kind: 'host'; games: GameInfo[] } | null;

/** What a name's menu offers: invite them to the table you're hosting, or host a game with them. */
export function inviteChoice(
  target: IdentityPublic,
  ctx: { me: IdentityPublic | null; status: Status | null; myTable: TableInfo | null; catalog: GameInfo[] },
): InviteChoice {
  const { me, myTable } = ctx;
  if (!me || target.id === me.id || target.released) return null;
  const hosting = myTable && myTable.status === 'forming' && myTable.host.id === me.id ? myTable : null;
  if (!hosting) return myTable ? null : { kind: 'host', games: ctx.catalog };
  const name = ctx.catalog.find((g) => g.id === hosting.gameId)?.name ?? hosting.gameId;
  const label = `Invite to ${name}`;
  const already = hosting.seated.some((p) => p.id === target.id) || hosting.invites.some((i) => i.to.id === target.id);
  if (already) return { kind: 'invite', label, disabled: 'Already at your table' };
  if (hosting.seated.length + hosting.invites.length >= hosting.size) return { kind: 'invite', label, disabled: 'Your table is full' };
  if (ctx.status !== 'ready') {
    const why = ctx.status === 'afk' ? 'AFK right now' : ctx.status === 'playing' ? 'In a match' : 'Not here';
    return { kind: 'invite', label, disabled: why };
  }
  return { kind: 'invite', label, disabled: null };
}
```

```ts
/** Every table action goes through the same routes an agent uses. */
export const tableApi = {
  host: async (gameId: string, invite?: string[]) =>
    mine((await api<{ table: TableInfo }>('POST', '/api/tables', { gameId, ...(invite?.length ? { invite } : {}) })).table),
  vsHouse: async (gameId: string, bot?: string) =>

  invite: async (tableId: string, handles: string[]) => mine((await api<{ table: TableInfo }>('POST', `/api/tables/${tableId}/invite`, { handles })).table),
  remove: async (tableId: string, handle: string) => mine((await api<{ table: TableInfo }>('POST', `/api/tables/${tableId}/remove`, { handle })).table),
  setOpen: async (tableId: string, open: boolean) => mine((await api<{ table: TableInfo }>('PATCH', `/api/tables/${tableId}`, { open })).table),
  sit: async (tableId: string) => mine((await api<{ table: TableInfo }>('POST', `/api/tables/${tableId}/sit`)).table),
  start: (tableId: string) => api<{ match: MatchSummary }>('POST', `/api/tables/${tableId}/start`),
  leave: async (tableId: string) => {
    await api('POST', `/api/tables/${tableId}/leave`);
    live.myTable = null;
  },
  disband: async (tableId: string) => {
    await api('DELETE', `/api/tables/${tableId}`);
    live.myTable = null;
  },
  rematch: async (tableId: string) => mine((await api<{ table: TableInfo }>('POST', `/api/tables/${tableId}/rematch`)).table),
  accept: async (inviteId: string) => {
    const t = (await api<{ table: TableInfo }>('POST', `/api/invites/${inviteId}/accept`)).table;
    live.offers = live.offers.filter((o) => o.invite.id !== inviteId);
    return mine(t);
  },
  decline: async (inviteId: string) => {
    live.offers = live.offers.filter((o) => o.invite.id !== inviteId);
    await api('POST', `/api/invites/${inviteId}/decline`);
  },
};

/** Invite someone to the table you're hosting. */
export async function inviteHandle(handle: string): Promise<void> {
  const t = live.myTable;
  if (!t) throw new Error('Host a table first.');
  await tableApi.invite(t.id, [handle]);
}

/** Host a table (and invite these people straight away). */
export async function hostWith(gameId: string, handles: string[] = []): Promise<void> {
  await tableApi.host(gameId, handles);
}

/** `/invite a, b [game]` from a chat box. Returns a line to show; throws with the reason. */
export async function runInviteCommand(words: string[], channel: string): Promise<string> {
  const { handles, game } = splitGame(words, live.games);
  if (handles.length === 0) throw new Error('Who? Try /invite DiceRoller');
  const names = handles.map((h) => `@${h}`).join(', ');
  const t = live.myTable;
  if (t && t.status === 'forming' && t.host.id === live.me?.id) {
    await tableApi.invite(t.id, handles);
    return `Invited ${names}.`;
  }
  if (t) throw new Error("You're at a table already. Leave it first.");
  const g = gameFor(game, channel, live.games);
  if (!g) throw new Error('Which game? Try /invite DiceRoller critical-mass');
  await hostWith(g.id, handles);
  return `Invited ${names} to ${g.name}.`;
}
```
